# عارض التقرير

| البند | القيمة |
|---|---|
| **اسم الكلاس** | `ReportViewScreen` (`ConsumerStatefulWidget`) — يستقبل `ReportId report` |
| **مسار الملف** | `lib/capabilities/oversight/presentation/report_view_screen.dart` |
| **المسار الملاحي** | `/home/reports/:reportCode` — `reportRoute(report)` |
| **اسم الشاشة في الشريط** | **`report.title`** — ⭐ **يتغيّر بتغيُّر التقرير** لا نصٌّ ثابت |

## الغرض
**عارضٌ واحدٌ لكلِّ الخمسةِ والعشرين تقريراً** — يبني شريطَ مرشِّحاته من نوع التقرير، ويعرض ترويسةً وجدولاً وإجمالياتٍ، ويُصدِّر PDF. ⛔ **ولا شاشةَ خاصّةً لأي تقرير.**

## مجموعاتُ المرشِّحات بحسب التقرير
شريطُ المرشِّحات **يُبنى ديناميكياً** (`_reportFilterGroups`) — المجموعةُ الأولى دائماً **المصدر**، ثم:

| التقرير | المجموعاتُ الإضافية |
|---|---|
| حركة النوع | **النوع** (بلا خيار «الكل» ⟵ **فالتقريرُ لا يُبنى بلا نوع**) |
| المخزون الحالي | **حالةُ التوفّر** («الكل» + قيم `StockAvailability`) · **النوع** |
| متبقي اليوم | **النوع** |
| الوارد عدداً | **الرعوي** · **النوع** |
| الوارد جواني | **الرعوي** · **الجونية** («كل الجواني» + جوانيُّ الفترة المختارة وحدها) |
| التوزيعات | **المقوت** |
| التسويات | **حالةُ التسوية** («الكل» + قيم `SettlementStatus`) · **المقوت** |
| بقيّةُ التقارير | المصدرُ والفترةُ وحدهما (وبعضُها يزيد الفئةَ ونوعَ البند وحالةَ الإيداع وحالةَ الرصيد كما يذكره فهرسُ التقارير) |

## شجرة الـ Widget tree
```
Scaffold
├── appBar: QtmsTopBar (report.title)
├── floatingActionButton: [شرطي مزدوج] FAB.extended «تصدير ومشاركة» → PDF + مشاركة النظام
└── ListView (حشو سفلي 96)
    ├── _ReportFilters
    │   ├── [لا مصادر] QtmsFilterBar.notice («لا يوجد مصدر ضمن نطاقك…»)
    │   └── QtmsFilterBar (padded: false)
    │       ├── مجموعة المصدر (+ «كل المصادر» إن سُمِح)
    │       └── مجموعاتٌ إضافيةٌ بحسب نوع التقرير (النوع · الرعوي · المقوت · الجونية · الحالة …)
    ├── _PeriodRow → Wrap
    │   ├── Text («تاريخ المخزون» | «تاريخ الإدخال» | «تاريخ السند» | «تاريخ الحركة»: …)
    │   ├── [مدى] TextButton «تغيير البداية» → showDatePicker
    │   └── TextButton («تغيير النهاية» | «تغيير التاريخ») → showDatePicker
    ├── switch (reportTableProvider)
    │   ├── isLoading | value null → SkeletonTile × 3
    │   ├── Failure               → QtmsErrorState (+ زرّ «إعادة المحاولة» ← invalidate)
    │   ├── Success(null)         → QtmsEmptyState («اختر ما يلزم لبناء التقرير» + الرسالة الخاصّة)
    │   └── Success(table)        → _ReportBody
    │       ├── QtmsKeyValueRow × table.header
    │       ├── [شرطي] QtmsInlineBanner (warning — table.incompleteWarning)
    │       ├── [صفوفٌ فارغة] QtmsEmptyState («لا حركة في هذا المدى»)
    │       │   [وإلا] QtmsDataTable (متجاوب · الملغى مشطوب)
    │       └── Container (surfaceSunken) → QtmsKeyValueRow × table.totals (كلُّها numeric)
    └── [شرطي] QtmsInlineBanner (success | danger — نتيجةُ التصدير)
```

## الحالات المُعالجة
| الحالة | الوضع |
|---|---|
| Loading | ✅ **ثلاثُ بطاقاتٍ هيكلية** — **وشريطُ المرشِّحات وصفُّ الفترة يبقيان ظاهرَين فوقها** ⟵ **فتغييرُ المرشِّح ممكنٌ أثناء البناء.** وأثناء التصدير يُعطَّل الزرُّ العائم ⛔ بلا مؤشّر عليه. |
| Error | ✅★ **كاملة:** `QtmsErrorState` برسالةٍ **من كتالوج الأخطاء** **مع زرِّ «إعادة المحاولة» الفعّال.** ⚠️ **بلا `detail` تقنيٍّ** هنا (بخلاف «كشف حساب المقوت»). ✅ ونتيجةُ التصدير بلافتةٍ ملوّنة. |
| Empty | ✅★ **ثلاثُ حالاتٍ متمايزةٍ تماماً** — وهو أدقُّ تفريقٍ للفراغ في التطبيق: **① مرشِّحٌ ناقص** («اختر ما يلزم…» برسالةٍ تقول أيَّ مرشِّح) · **② لا صفوف** («لا حركة في هذا المدى» بإصلاحَين مقترحَين) · **③ لا مصدرَ في النطاق** (لافتةٌ مكانَ شريط المرشِّحات). ⟵ **فلا تُخلَط «لم تختر» بـ«لا بيانات» بـ«لا صلاحية».** |
| نقصٌ بنيوي | ✅ `incompleteWarning` بلافتةٍ ذهبيةٍ من طبقة النطاق. |
| رمزٌ غيرُ معروف | ✅ **مُعالَجٌ في الموجّه لا هنا:** `ReportId.tryParse` تُرجِع `null` ⟶ فيُبنى `ReportsScreen` بدلاً منها ⛔ **فلا شاشةَ خطأٍ ملاحيّ.** |

## آلية التنقل
- **الدخول إليها:** **من `/home/reports` وحدها** — النقرُ على بطاقة تقرير (والفهرسُ يكتب الطلبَ قبل الإبحار). **ويصحّ الدخولُ المباشر بالمسار** لأن `initState` يُصلِح الطلبَ.
- **الخروج منها:** ⛔ **لا مسارَ داخليٍّ خارجاً ولا ورقةَ سفلية** — و`showDatePicker` هو الحوارُ الوحيد. **لكنّ التصدير يفتح ورقةَ مشاركة النظام** لتسليم الـPDF. الرجوع بزرّ النظام.
