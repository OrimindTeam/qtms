## الغرض
فهرسُ التقارير **مجموعاً بعائلاته** — ★ **ولا يُعرَض منه إلا ما يملك المستخدم مفتاحَ عرضه** (`visibleReportsProvider`)، **والعائلةُ الخاليةُ تُحجَب كلَّها**. وكلُّ بطاقةٍ تقول **مرشِّحاتِ التقرير قبل فتحه** ⟵ فيعرف المستخدم ما سيُطلَب منه.

## عائلاتُ التقارير الخمسٌ والعشرون تقريراً
الفهرسُ يعرض التقاريرَ مجموعةً في عائلاتٍ (`ReportFamily`)، وهذه هي كلُّها مع مرشِّحاتها كما يعرضها النصُّ الثانوي:

| التقرير | المرشِّحات المعروضة |
|---|---|
| حركة النوع (`itemMovements`) | المصدر · النوع · الفترة |
| المخزون الحالي (`currentStock`) | المصدر · التاريخ · الحالة · النوع |
| الوارد عدداً (`countedIntakes`) | المصدر · الفترة · الرعوي · النوع |
| الوارد جواني (`sackIntakes`) | المصدر · الفترة · الرعوي · الجونية |
| متبقي اليوم (`todayRemainder`) | المصدر · التاريخ · النوع |
| الهالك والإتلاف (`wasteAndDisposal`) | المصدر · الفترة · الرعوي |
| التوزيعات (`distributions`) | المصدر · الفترة · المقوت |
| ملخّص توزيع المقاوته (`dealerDistributionSummary`) | المصدر · الفترة |
| التسويات (`settlements`) | المصدر · الفترة · حالة التسوية · المقوت |
| المبيعات النقدية (`cashSales`) | المصدر · الفترة |
| المبيعات بالنوع (`salesByItem`) | المصدر · الفترة |
| السطور غير المسعَّرة (`unpricedLines`) | المصدر · الفترة · المقوت |
| المقبوضات (`receipts`) | المصدر · الفترة · حالة الإيداع |
| الخصومات (`discounts`) | المصدر · الفترة |
| حركة النقد (`cashMovement`) | المصدر · التاريخ |

| ضمار المالك اليومي (`ownerLedgerDaily`) | المصدر · الفترة |
| السحبيات (`withdrawals`) | المصدر · الفترة · الفئة · نوع البند |

## شجرة الـ Widget tree
```
Scaffold (بلا FAB)
├── appBar: QtmsTopBar («التقارير»)
└── body
    ├── [لا عائلات مرئية] QtmsEmptyState («لا تقرير ضمن صلاحياتك»)
    └── ListView (padding: 16)
        └── لكل عائلة مرئية:
            ├── SectionHeader (family.label — titleMd)
            ├── لكل تقريرٍ في العائلة مملوكٍ مفتاحُه:
            │   └── Padding(سفلي 12) → EntityTile (onTap → فتحُ التقرير)
            │       ├── leading: IconBadgeBox (description_outlined · neutral · 48)
            │       ├── title:   Text (report.title — titleSm)
            │       └── subtitle:Text (مرشِّحاتُ التقرير مفصولةً بـ « · »)
            └── SizedBox (8)
```

## الحالات المُعالجة
| الحالة | الوضع |
|---|---|
| Loading | ⛔ **لا حالةَ تحميلٍ إطلاقاً** — القائمةُ مُشتقّةٌ من صلاحيات الجلسة المحمَّلة، **فتُبنى فوراً** بلا استعلامٍ شبكي. |
| Error | ⛔ **لا حالةَ خطأ** — لا نداءَ شبكةٍ في هذه الشاشة. |
| Empty | ✅ «لا تقرير ضمن صلاحياتك» برسالةٍ تشرح **لماذا** وتقول **ما يفعله المستخدم** (راجع المدير). ✅ **وحجبٌ على مستويَين:** التقريرُ الذي لا يملك مفتاحَه يُحجَب، **والعائلةُ التي خلت من تقاريرها تُحجَب بترويستها** ⟵ **فلا عنوانَ عائلةٍ معلَّقٌ بلا بطاقات.** |

## آلية التنقل
- **الدخول إليها:** «لوحة اليوم» ⟶ قسم «الرقابة» ⟶ «التقارير» — ⚠️ **وشرطُ ظهور المدخل ليس `PermissionGate`** بل `visibleReportsProvider.isNotEmpty` ⟵ **فالمدخلُ يغيب إن لم يملك المستخدم مفتاحَ تقريرٍ واحد.**
- **الخروج منها:** ⟶ **`/home/reports/{reportCode}`** لكلِّ بطاقة — و[`report_view_screen.md`](report_view_screen.md) هي الشاشةُ الهدف. **وإن كان الرمزُ غيرَ معروفٍ يُعيد الموجّهُ هذه الشاشةَ نفسَها** (`ReportId.tryParse` تُرجِع `null` ⟶ `ReportsScreen`) ⟵ **فلا شاشةَ خطأٍ ملاحيٍّ ولا 404.** الرجوع بزرّ النظام.
