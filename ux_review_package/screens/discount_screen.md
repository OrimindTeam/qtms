## الغرض
إسقاطُ مبلغٍ من ذمّة مقوتٍ **بلا أي أثرٍ نقدي** — ⛔ **لا يدخل الصندوق.** ★ **والخصمُ يُدخَل كخصمٍ لا كمبلغٍ واصل** — وهي القاعدةُ التي تفرّقه عن «المقبوضات». وبنيتُها **توأمٌ شبهُ حرفيٍّ لشاشة المقبوضات** مع فوارقَ مقصودة (انظر جدولَ الفوارق أدناه).

## الفوارقُ عن شاشة «المقبوضات» — جدولٌ مقارن
البنيتان متطابقتان تقريباً، والفوارقُ كلُّها مقصودةٌ ومعنويّة:

| البند | المقبوضات | الخصومات |
|---|---|---|
| تسميةُ حقل السطر | «الواصل» | **«الخصم»** |
| مفهومُ الفائض | ✅ `_SurplusField` + نطاقُ فائضٍ (عامّ/مصدر) + تحذيرٌ يقترح التوزيع | ⛔ **غيرُ موجودٍ إطلاقاً** |
| مصدرُ مبلغِ التوزيع التلقائي | الإجماليُّ المكتوبُ حالياً في الحقول + الفائض | **حقلٌ مستقلٌّ «مبلغ للتوزيع التلقائي»** |
| الباقي غيرُ الموزَّع | يذهب إلى حقل الفائض | **يُعلَن نصّاً: «⚠️ … لم تُوزَّع»** |
| حالةُ «لا ضمارات مفتوحة» | لا تُوقِف العمل — الفائضُ ما زال ممكناً | **تُوقِف العمل: «ولا شيء يُخصَم منه»** |
| الإرسال والتصدير | ✅ زرٌّ يظهر بعد الحفظ (واتساب · رسائل · PDF) | ⛔ **لا شيء** |
| سطرُ القاعدة في الملخّص | «على الضمارات» و«فائض» | **«بلا أثر نقدي — لا يدخل الصندوق»** |
| إبطالُ القراءات بعد الحفظ | الضمارات **والفائضُ المتاح** | **الضماراتُ وحدها** |

## شجرة الـ Widget tree
```
Scaffold (بلا FAB)
├── appBar: QtmsTopBar («الخصومات»)
└── Column
    ├── _DiscountHeader
    │   ├── DropdownButtonFormField «المقوت»
    │   └── DropdownButtonFormField «المصدر» (+ «كل المصادر» بلا شرط)
    ├── Divider (1px)
    └── Expanded
        ├── [بلا مقوت] QtmsEmptyState («اختر المقوت»)
        └── _DiscountForm → lotsAsync.when
            ├── loading → SkeletonList
            ├── error   → QtmsErrorState (operationFailed + detail)
            └── data → Column
                ├── Expanded → ListView (16)
                │   ├── _DebtBanner («إجمالي الديون… (N ضمار مفتوح)»)
                │   ├── _DateRow → TextButton «تغيير» → showDatePicker
                │   ├── [لا ضمارات] QtmsEmptyState («لا ضمارات مفتوحة — ولا شيء يُخصَم منه»)
                │   │   [وإلا]
                │   ├── _LotRow × N
                │   │   ├── Text «ضمار {التاريخ} — مصدر {sourceId}»
                │   │   └── Row: Text «المتبقي: …» | TextField «الخصم» (+errorText) | Text «بعده: …»
                │   └── _AutoAllocateField
                │       ├── TextField «مبلغ للتوزيع التلقائي» (helperText)
                │       └── OutlinedButton.icon «توزيع تلقائي (الأقدم أولاً)»
                └── QtmsStickyActionBar
                    ├── summary: QtmsLiveSummary (الخصم · عدد الضمارات · «بلا أثر نقدي» · emphasis: الديون)
                    ├── status:  [شرطي] Text (✅/❌/⚠️)
                    └── primary: FilledButton («حفظ سند الخصم» | «جارٍ الحفظ…»)
```

## الحالات المُعالجة
| الحالة | الوضع |
|---|---|
| Loading | ✅ `SkeletonList` لقراءة الضمارات، **ونصُّ زرٍّ متغيّر** («جارٍ الحفظ…»). |
| Error | ✅ `QtmsErrorState` بنصّ `operationFailed` **مع `detail` تقنيٍّ قابلٍ للطيّ**. ⚠️ **بلا تمييزٍ لـ`permission-denied`** وبلا زرّ إعادة محاولة. ⚠️ **وسطرُ حالةِ الكتابة نصٌّ عارٍ** بلا ثلاثيةِ لون — **مع أنه يحمل ثلاثَ درجاتٍ من الشدّة** (`✅`/`⚠️`/`❌`) تستحقّ تمييزاً لونياً. |
| Empty | ✅ **حالتان متمايزتان:** «اختر المقوت» · **و«لا ضمارات مفتوحة» — وهي هنا حالةٌ نهائيةٌ توقف العمل** بخلاف نظيرتها في «المقبوضات». |
| ⚠️ **حرسٌ ناقص** | `errorText` «يتجاوز المتبقي» يُوسَم لحظياً ⛔ **لكنّه لا يُعطِّل زرَّ الحفظ** — فالرفضُ يأتي من الخادم. |
| عدمُ الاستيعاب | ✅ ★ **مُعالَجٌ بقيمته:** «⚠️ {N} ريال لم تُوزَّع — المبلغ يتجاوز ما على المقوت في هذا النطاق.» ⟵ **فالمستخدم يعرف كم لم يُوزَّع لا أن شيئاً لم يُوزَّع.** |
| النجاح | ✅ رسالةٌ برقم السند · تفريغُ النموذج · وإبطالُ قراءةِ الضمارات فتُحدَّث فوراً. |

## آلية التنقل
- **الدخول إليها:** «لوحة اليوم» ⟶ «العمليات اليومية» ⟶ «الخصومات» (بمفتاح `discountCreate`).
- **الخروج منها:** ⛔ **لا مسارَ خارجاً ولا ورقةَ سفلية ولا تطبيقٍ خارجي** — و`showDatePicker` هو الحوارُ الوحيد. الرجوع بزرّ النظام.
- **أثرٌ ظاهرٌ في شاشةٍ أخرى:** الخصمُ يُعرَض في «ضمار المالك» بصفَّي **«قبل الخصم»** و**«بعد الخصم»**، والصافي النهائي على الثاني.
