# المخططات الهيكلية (Wireframes) — QTMS

| البند | القيمة |
|---|---|
| **الطبيعة** | LIVING |
| **المالك** | UX |
| **الحالة** | ⏳ **لا مخططات — لم تبدأ مرحلة الواجهات** |

---

## 1. ★ متى يُرسَم مخطط

> ⛔ **لا يُرسَم مخطط لشاشة تنتمي لنمط قائم بلا تعديل** — ★ **النمط نفسه هو
> المخطط**، ورسمه مجدداً **يُنتج نسختين تتباعدان.**

| ✅ يُرسَم | ⛔ لا يُرسَم |
|---|---|
| ★ **شاشة بتخطيط يخرج عن الأنماط التسعة** | شاشة قائمة كيانات عادية |
| ★ **شاشة مالية معقّدة** (بطاقة ضمار المالك) | نموذج بسيط |
| ★ **تدفّق متعدد الخطوات** (اعتماد التوزيع · تصفية متأخرة) | إعدادات |
| **شاشة يصعب وصفها نصّاً** | — |

## 2. التسمية

```text
WF-<الوحدة>-<الشاشة>.md
```

## 3. ★ المحتوى الإلزامي

```markdown
# WF-<المعرّف> — <العنوان>

| البند | القيمة |
|---|---|
| ★ **النمط المنتمي إليه** | نمط <رقم> من ui-guidelines |
| **الوحدة** | FR-M* |
| ★ **سؤال الشاشة الواحد** | ← ★ إلزامي |

## التخطيط
## ★ مصدر كل رقم معروض   ← ★ دفتر أم ملخص؟
## ★ التاريخ المعروض      ← ★ stockDate أم entryDate؟
## الحالات الست           ← تحميل · فارغ · خطأ · محتوى · انقطاع · بلا صلاحية
## ★ ما يُخفى بلا صلاحية
## الإجراء الأساسي الواحد
```

## 4. ★ قواعد

| # | القاعدة |
|---|---|
| 1 | ★ **كل مخطط يُصرِّح بنمطه** — ⛔ **ولا يخترع تخطيطاً** |
| 2 | ★ **كل رقم يُصرِّح بمصدره** — ★ **الملخص للعرض والدفتر للحقيقة** |
| 3 | ★ **كل تاريخ يُصرِّح بنوعه** |
| 4 | ★ **الحالات الست موصوفة لا مفترضة** |
| 5 | **مصطلحات المجال من المعجم الموحَّد** |
| 6 | ⛔ **لا بيانات حقيقية في أي مخطط** |
