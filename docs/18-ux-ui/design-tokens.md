# رموز التصميم (Design Tokens) — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | **M** |
| **الطبيعة** | **STATIC** — لا تُعدَّل قيمة بعد اعتمادها دون تنبيه صريح |
| **المالك** | UX / DEV |
| **المصدر** | ★ **إدخال مكتبة التصميم المعتمد** (`DS-001`) |

> ★ **هذا الملف مصدر الحقيقة لكل قيمة بصرية في QTMS.** ★ **أي لون أو حجم خط
> أو نصف قطر أو ظل مكتوب خارج هذه الطبقة يُرفَض في المراجعة.**

---

## 1. ★ البنية ثلاثية الطبقات

```text
أولية (Primitive)  →  دلالية (Semantic)  →  مكوّن (Component)
   قيمة خام              معنى                  استخدام
```

| القاعدة |
|---|
| ★ **الشاشات تستدعي الطبقة الدلالية فقط** |
| ★ **المكوّنات تستدعي الطبقة الدلالية فقط** |
| ⛔ **الطبقة الأولية لا تُستدعى خارج ملف التوكنز إطلاقاً** |
| ★ **القراءة عبر آلية الثيم لا عبر ثوابت ساكنة** — ★ **موضعُ التغيير يبقى واحداً، والثابت المحفور في شاشة يهرب من كل مراجعة** |

> ★ **بعد `AM-003`: آلية الثيم أُبقيت بنيوياً — ⛔ لكن مجموعة القيم واحدة
> لا مجموعتان.** ★ **إبقاؤها ممارسة تقنية سليمة** (نقطة حقن واحدة للقيم،
> وشاشةٌ لا تعرف مصدرها)، ⛔ **ولا يعني إبقاؤها وجود اختيار وضع**:
> **الوضع الفاتح هو الوضع الوحيد، ولا `ThemeMode` ولا قراءة لتفضيل النظام.**

> «فاتح/داكن» على أي توكن.** ★ **والقيم الداكنة الملغاة محفوظة في**
> [`../99-archive/2026/design-tokens-dark-mode-AM-003.md`](../99-archive/2026/design-tokens-dark-mode-AM-003.md)
> ⛔ **سجلاً تاريخياً لا مرجعاً حيّاً.**

## 4. ★ توكنز البطاقة الرئيسية (Hero)

> ★ **البطاقة الرئيسية سطحٌ داكن فوق خلفية فاتحة** — ★ **فتحتاج طقم نص خاصاً
> بها** ⛔ **لا يُستعار من توكنز السطح العادي.**

| Token | القاعدة |
|---|---|
| `heroGradient` | تدرّج قطري من أعلى-النهاية إلى أسفل-البداية: `primary600 → primary900` |
| `textOnHero` | نص فاتح `#F7F9FC` |
| `successOnHero` / `dangerOnHero` | `success #7BD3A0` · `danger #F49A9A` |
| `heroLabelOpacity` | ★ **78٪ كحدّ أدنى — لا أقل** |

> ⚠️ ★ **قيمة واحدة لكل توكن هنا** — ⛔ **ولا شرط وضع** (`AM-003`).
> ★ **والتوكن `textOnHero` قائم بذاته لا مشتقٌّ من `textOnInverse`**: ★ **الأول
> يصف نصاً على تدرّج البطاقة، والثاني نصاً على `surfaceInverse`** — ★ **وخلطهما
> يجعل تغيير أحدهما يغيّر الآخر بلا قصد.**

## 5. ★ التايبوغرافيا

| Token | Size | Weight | Line Height | Letter Spacing | الاستخدام في QTMS |
|---|---|---|---|---|---|
| `displayLg` | 32 | 700 | 1.25 | -0.5 | ★ **الرقم الرئيسي في البطاقة الرئيسية** |
| `displaySm` | 26 | 700 | 1.30 | -0.3 | رقم ثانوي كبير |
| `titleLg` | 20 | 700 | 1.35 | -0.2 | عنوان شاشة أو ورقة |
| `titleMd` | 17 | 600 | 1.40 | 0 | عنوان قسم |
| `titleSm` | 15 | 600 | 1.45 | 0 | عنوان بطاقة |
| `bodyLg` | 15 | 400 | 1.60 | 0 | نص رئيسي |
| `bodyMd` | 13.5 | 400 | 1.60 | 0 | نص ثانوي |
| `label` | 13 | 600 | 1.40 | 0 | تسميات الأزرار والحقول |
| `caption` | 12 | 400 | 1.40 | 0.1 | تلميحات وأزمنة |
| ★ `numeric` | — | 600 | 1.20 | 0 | ★ **كل رقم في جدول — بأرقام جدولية** |

| القاعدة |
|---|
| **الحد الأدنى `12`** · ⛔ **لا حروف كبيرة في النص العربي** |
| ★ **ارتفاع السطر العربي ≥ 1.6 · وتباعد الأحرف = 0 دائماً** |
| ⛔ **لا أكثر من ثلاثة أحجام خط في شاشة واحدة** |
| ★ **الهرمية من الوزن واللون لا من تضخيم الحجم** |
| ★ **تكبير حتى `1.3×` بلا كسر ولا قصّ** |

> ★ **`numeric` ليس توكناً تجميلياً في QTMS:** ★ **بدون الأرقام الجدولية
> تهتزّ أعمدة الجداول المالية عند كل تحديث** — **وتُصعِّب المقارنة البصرية
> التي يعتمد عليها المالك.**
>
> ✅ **الخط المعتمَد: IBM Plex Sans Arabic** — ★ **أرقامه اللاتينية ثابتة
> العرض (600 وحدة) ومُتحقَّق منها.**
> ⚠️ ★ **لكن أرقامه الهندية (٠-٩) متغيّرة العرض** — ⛔ **فلا تُعرَض في جدول
> مالي إطلاقاً** ([`../19-assets/fonts/README.md`](../19-assets/fonts/README.md) §3).

## 8. الظلال

| Token | القيمة |
|---|---|
| `e0` | لا شيء |
| `e1` | إزاحة 4 · ضبابية 12 · شفافية 6٪ |
| `e2` | إزاحة 8 · ضبابية 24 · شفافية 8٪ |
| `e3` | إزاحة 12 · ضبابية 32 · شفافية 12٪ |

> ★ **السمة المميِّزة: إزاحة صغيرة + ضبابية كبيرة + شفافية منخفضة جداً** —
> إحساس «هواء تحت البطاقة» لا «طبقة معدنية».
> ⛔ **ممنوع ظل الإطار الافتراضي** · ⛔ **ممنوع ظل وحدّ معاً على العنصر نفسه.**

## 9. الحركة

**المدد:** `durationFast = 120ms` · `durationBase = 220ms` ·
`durationSlow = 320ms` · `shimmer = 1200ms`.

**المنحنيات:** `curveStandard = easeInOutCubic` · `curveEnter = easeOutCubic` ·
`curveExit = easeInCubic`.

> ⛔ **لا حركة تتجاوز `400ms`** · ⛔ **لا ارتداد ولا مطاطية** ·
> ★ **إعداد «تقليل الحركة» محترَم دائماً — والحركة تُلغى لا تُبطَّأ.**

## 10. الأبعاد

`fieldHeight = 52` · `buttonPrimaryHeight = 52` · `buttonSecondaryHeight = 44` ·
`chipHeight = 36` · `listRowHeight = 72` · `tileMinHeight = 56` ·
`appBarHeight = 56` · `iconBox = 48` · `iconSm = 16` · `iconMd = 20` ·
`iconLg = 24` · `avatarSm = 36` · `avatarMd = 44` · `avatarLg = 64` ·
`borderWidth = 1` · `focusWidth = 2` · ★ `minTouch = 48`.

## 11. ★ بوابة الجودة — شرط لا رفاهية

```text
★ فحص آلي يرفض أي قيمة لون أو حجم خط أو نصف قطر أو ظل مكتوبة خارج هذه الطبقة.
```

> ★ **بلا هذه البوابة تتسرّب القيم اليدوية خلال أسابيع** ★ **ويسقط النظام إلى
> مجرد توصية.** **صيغة الفحص تتبع المكدّس التقني — لكن وجودها إلزامي.**
