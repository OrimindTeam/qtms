## 2. ★ من يُختبَر معه

| المشارك | الأولوية | لماذا |
|---|---|---|
| ★ **المالك** | 🔴 | ★ **هو من يقرأ الأرقام ويبني عليها القرار** |
| ★ **أمين المخزن** | 🔴 | ★ **الإدخال السريع تحت ضغط الوقت** |
| **المحاسب** | 🟠 | الدقة والمطابقة |
| **الموزّع** | 🟠 | الاستخدام الميداني |

## 3. ★ المهام المرشَّحة

| # | المهمة | ما تكشفه |
|:-:|---|---|
| 1 | ★ **إدخال توزيعة كاملة تحت ضغط الوقت** | ★ **هل السرعة كافية فعلاً؟** |
| 2 | ★ **قراءة بطاقة ضمار المالك والحكم على اليوم** | ★ **هل الأرقام مفهومة بلا شرح؟** |
| 3 | **تصفية متبقٍّ متأخر** | ★ **هل ازدواج التاريخ مفهوم؟** |
| 4 | **تعديل حركة معتمَدة** | هل السبب النصّي مقبول أم عائق؟ |
| 5 | **العمل عند انقطاع الشبكة** | ★ **هل يفهم المستخدم أن الحفظ لم يحدث؟** |

> ★ **المهمة 5 هي الأهم أمنياً:** ★ **إن ظن مشارك واحد أن عمله حُفظ وهو لم
> يُحفَظ — فهذا خلل حاجب لا ملاحظة تجربة.**

## 4. ★ ما يُقاس

| المقياس |
|---|
| **إتمام المهمة بلا مساعدة** |
| ★ **الزمن مقارنة بالطريقة اليدوية الحالية** |
| ★ **الأخطاء — وأخطرها: إدخال في المصدر أو اليوم الخطأ** |
| ★ **سوء فهم المصطلحات** |
| ★ **سوء قراءة رقم** — ⛔ **وهذا حاجب** |

## 5. ★ التصنيف

| الشدّة | مثال |
|---|---|
| ⛔ **حاجب** | ★ **مستخدم يقرأ رقماً خطأ · أو يظن أن حفظاً حدث ولم يحدث** |
| 🔴 **حرج** | لا يستطيع إتمام مهمة أساسية |
| 🟠 **مهم** | يتمّها ببطء أو بمساعدة |
| 🟡 **بسيط** | تفضيل شكلي |
