# النماذج التفاعلية — QTMS

| البند | القيمة |
|---|---|
| **الطبيعة** | LIVING |
| **المالك** | UX |
| **الحالة** | ⏳ **لا نماذج** |

---

## 1. ★ متى يُبنى نموذج تفاعلي

> **النموذج التفاعلي كلفة** — ★ **فيُبنى حين يكون السؤال «هل يفهمه المستخدم؟»
> لا «كيف يبدو؟».**

| المحفّز |
|---|
| ★ **تدفّق مالي متعدد الخطوات قبل برمجته** — اعتماد التوزيع · القبض بتوزيع تلقائي |
| ★ **شاشة الإدخال السريع** — ★ **السرعة الفعلية لا تُقاس على ورق** |
| ★ **بطاقة ضمار المالك** — ★ **تُعرَض على المالك قبل بنائها** |
| **تدفّق تصفية المتبقي المتأخر** |

## 2. ★ الأولوية القصوى

> ★ **أهم نموذج ممكن هنا: عرض بطاقة ضمار المالك على المالك نفسه قبل برمجتها.**
>
> ★ **هو الوحيد الذي يعرف كيف يقرأ أرقامه فعلاً** — ★ **وتصحيح الترتيب أو
> التسمية على نموذج أرخص بمراحل من تصحيحه بعد بناء الملخصات كلها.**

## 3. ★ قواعد

| # | القاعدة |
|---|---|
| 1 | ⛔ **بيانات وهمية فقط** — ★ **ولو عُرض على المالك** |
| 2 | ★ **بالعربية RTL دائماً** |
| 3 | ★ **الأرقام واقعية المقدار** — ★ **حتى تُختبَر المحاذاة والاتساع فعلاً** |
| 4 | ★ **النموذج ليس مصدر حقيقة** — ★ **والمعتمد ما في `docs/`** |
| 5 | **الملاحظات تُحوَّل لبنود لا تبقى في النموذج** |
