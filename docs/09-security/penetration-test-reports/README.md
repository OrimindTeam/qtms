# تقارير اختبار الاختراق — QTMS

| البند | القيمة |
|---|---|
| **الطبيعة** | LOG |
| **المالك** | SEC |
| **الحالة** | ⏳ **لا تقارير — لم يُقرَّر إجراء اختبار خارجي بعد** |

---

## 1. الحالة

> **المستند المصدر لم يذكر اختبار اختراق خارجياً.** ★ **ولم يُنشأ بند مدخلات
> بشرية لهذا** — لأنه **قرار يُتَّخذ عند اقتراب النشر الإنتاجي**، لا شرط
> لبدء التوثيق أو التنفيذ.

**متى يصبح القرار مطروحاً فعلاً:**

| المحفّز |
|---|
| **قبل النشر الإنتاجي الأول** |
| **بعد أي تغيير جوهري في نموذج التفويض** |
| **عند توسّع عدد المستخدمين أو المصادر بشكل ملحوظ** |
| **بعد أي حادثة أمنية حقيقية** |

## 2. ما يُختبَر لو أُجري — الأولوية

| # | المجال | لماذا |
|:-:|---|---|
| 1 | ★ **قواعد الحماية بالوصول المباشر** | ★ **طبقة التفويض الوحيدة** |
| 2 | ★ **رفع الامتياز** | يفتح كل ما بعده |
| 3 | ★ **تجاوز نطاق المصادر** | حدّ العزل الأعلى |
| 4 | ★ **مسّ سجل التدقيق** | يهدم مبرر التعديل المباشر |
| 5 | **العميل المُعدَّل** | تجاوز الواجهة كلياً |
| 6 | **العمليات السحابية** | فحص الصلاحية داخلها |

| # | القاعدة |
|---|---|

| 3 | **بنطاق مكتوب متفق عليه مسبقاً** |
