## 1. لماذا لا يوجد «تحديد معدل» بالمعنى التقليدي

> **لا توجد واجهة برمجية عامة ولا مستهلكون خارجيون** — والمستخدمون فريق
> صغير معروف بالاسم داخل منشأة واحدة. **فليست هناك حاجة لحدّ معدل ضد إساءة
> استخدام خارجية.**

## 2. القيد الأول — **الحصص والتكلفة السحابية** *(الأهم)*

> نصّ المستند المصدر صراحةً: **«عدد القراءات والكتابات هو المحرّك الأساسي
> للفاتورة»**، **و«إعادة الاحتساب بأثر رجعي وإعادة احتساب سعر الجونية
> عمليتان مكلفتان»**.

| الإجراء | التفصيل | إلزامي؟ |
|---|---|---|
| **تنبيهات الميزانية** | تُضبَط **منذ اليوم الأول** — **بند في بوابة الخطوة صفر** | ✅ **إلزامي** |
| **سقف التنبيه الشهري** | ⏳ **قيمة يحددها المالك** — بند في `release-checklist.md` | ✅ |
| **الملخصات الجاهزة** | القراءة من ملخص واحد بدل تجميع الدفاتر عند كل فتح شاشة | ✅ `ADR-0008` |
| **إعادة الاحتساب بتجميع** | لا بعد كل حركة منفردة حيث أمكن | ✅ `NFR-PERF-05` |
| **استعلامات مفهرسة ضيقة + ترقيم صفحات** | لا قراءة فترة كاملة دفعةً واحدة | ✅ |
| **تجنّب المستمعين اللحظيين واسعي النطاق** | الاستماع على الملخص لا الدفتر | ✅ |
| **مراجعة دورية لأكثر الاستعلامات استهلاكاً** | شهرياً | ✅ |

**المؤشرات المتابَعة:** `K-23` إجمالي القراءات/الكتابات · `K-24` تكلفة
إعادة الاحتساب · **`K-25` عدد تنبيهات تجاوز الميزانية = صفر**.

## 3. القيد الثاني — **منع الإساءة والالتفاف**

| الطبقة | ما تمنعه |
|---|---|
| **فحص العميل الرسمي** | **أي عميل غير التطبيق** — يسبق كل طلب |
| **قواعد الحماية** | **الرفض هو الأصل** — أي مسار لم يُذكَر ممنوع |
| **قفل الحساب** | بعد عدد محاولات دخول فاشلة متتالية |
| **إبطال الجلسة فوراً** | عند تعطيل المستخدم |
| **تسجيل المحاولات المرفوضة** | **محاولة الكتابة من أداة خارجية تُسجَّل كمحاولة وصول غير مصرّح** (`E-42`) |

> **الحماية هنا ليست حدّ معدل بل حدّ صلاحية** — ومن لا يملك الصلاحية
> **يُرفَض من الطلب الأول لا بعد ألف طلب**.

## 4. القيد الثالث — **حدود الإدخال في التطبيق**

> **الغرض حماية تجربة المستخدم وأداء المعاملة، لا الأمن.**

| الحد | القيمة المقترحة 🔶 | السبب |
|---|---|---|
| سطور المستند الواحد | **بلا حد منصوص** — لكن **تحذير بعد ~50 سطراً** | المعاملة الذرّية تكبر فيبطؤ الحفظ |
| نتائج التقرير في الصفحة | **ترقيم صفحات إلزامي** | «تقرير شهري < 5 ثوانٍ» |
| **التوزيع الجماعي** | **يُحفَظ داخل معاملة واحدة** — والحجم الكبير يُقسَّم | حد المعاملة في المنصة |
| **إنشاء الحسابات عند إضافة مصدر** | **بتجميع في السحابة** | 50 مقوتاً + 10 رعية = **60 كتابة** |

> 🔶 = **افتراضات قياسية أضفناها** — لم يذكر المصدر أرقاماً، **وتُضبَط من
> قياس فعلي** بعد أول شهر تشغيل.

## 5. ما لا ينطبق هنا

| المستبعَد | السبب |
|---|---|
| «100 طلب/دقيقة للمستخدم العادي» | **لا API عامة ولا مستهلكون خارجيون** |
| مفاتيح API وحصص لكل مفتاح | **لا مفاتيح** — المصادقة بحساب مستخدم |
| ترويسات `X-RateLimit-*` | **لا HTTP بيننا وبين القاعدة** |
| حظر عناوين IP | خارج تحكم التطبيق — يُدار على مستوى المنصة إن لزم |
