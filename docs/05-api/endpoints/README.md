# لا توجد نقاط نهاية في هذا المشروع — وهذا قرار لا سهو

**لا توجد في نظام QTMS واجهة برمجية ولا نقاط نهاية** (`ADR-0001`).
التطبيق يتصل مباشرةً بقاعدة البيانات السحابية، ويستدعي **عمليات سحابية**
لما لا يجوز أن يقوم به الجهاز.

**بديل هذا المجلد:** كتالوج العمليات السحابية في
[`../api-overview.md`](../api-overview.md) §3 — وفيه لكل عملية: المدخلات ·
المخرجات · شرط الاستدعاء · وسلوك الفشل.

يبقى هذا المجلد فارغاً عمداً حتى يُقرَّر خلاف ذلك بـ`CR` و`ADR` جديدين.
