# لا يوجد ملف OpenAPI في هذا المشروع — وهذا قرار لا سهو

**لا توجد في نظام QTMS واجهة برمجية (API) ولا نقاط نهاية (Endpoints)**
(`§2.1` و`§10` من المستند المصدر · `ADR-0001`).

التطبيق يتصل **مباشرةً** بقاعدة البيانات السحابية عبر حزم المنصة الرسمية:
**لا خادم تطبيق · لا REST API · لا GraphQL · لا جداول SQL.**

ولذلك فإن `openapi.yaml` **غير منطبق**، ويبقى هذا المجلد فارغاً عمداً.

## أين العقد إذن؟

| العقد | مكانه |

| **عقد العمليات السحابية** (المدخلات · المخرجات · شروط الاستدعاء) | [`../api-overview.md`](../api-overview.md) §3 |
| **المصادقة والتفويض** ومطالبات رمز الدخول | [`../authentication-and-authorization.md`](../authentication-and-authorization.md) |
| **أكواد الأخطاء** | [`../error-codes-catalog.md`](../error-codes-catalog.md) |
| **مخطط البيانات** (وهو العقد الفعلي بين التطبيق والقاعدة) | [`../../06-database/data-dictionary.md`](../../06-database/data-dictionary.md) |
| **قواعد الحماية** (طبقة التفويض الوحيدة) | [`../../09-security/security-requirements.md`](../../09-security/security-requirements.md) |

## متى يُنشَأ ملف OpenAPI مستقبلاً؟

**فقط** إن أُضيفت واجهة برمجية عامة فعلية — وهو ما يستلزم `CR` معتمَداً
و`ADR` جديداً يشير إلى `ADR-0001` بوصفه مُستبدَلاً أو مُعدَّلاً.
