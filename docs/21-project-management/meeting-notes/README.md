## 3. ★ قاعدة حاكمة

> ★ **المحضر ليس مصدر حقيقة.**
>
> ★ **القرار المتَّخَذ في اجتماع لا يصير نافذاً حتى يُنقَل إلى مستنده الرسمي**
> — `FR-*` أو `ADR` أو `srs.md` أو إجابة بند `OQ`.
>
> ⛔ **وقرار يعيش في محضر فقط قرار ضائع** — لأن **من يكتب الكود يقرأ
> `docs/` لا المحاضر.**
