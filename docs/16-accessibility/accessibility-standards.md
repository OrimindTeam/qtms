# معايير إمكانية الوصول — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | **M** |
| **الطبيعة** | **STATIC** |
| **المالك** | DEV / UX |
| **المرجع** | **WCAG 2.1 AA** (المستوى المستهدف) |

> ★ **الإتاحة هنا قيد بصري لا بند امتثال لاحق:** ★ **قيم نظام التصميم نفسها
> اختيرت لتجتاز الحدود أدناه**، **وأي قيمة جديدة تُختبَر قبل اعتمادها لا بعد
> ظهورها في شاشة.**

---

## 1. ★ لماذا هذا حرج في QTMS تحديداً

| السبب | الأثر |
|---|---|
| ★ **المستخدمون ميدانيون لا مكتبيون** | إضاءة متغيّرة · استعجال · جهاز بيد واحدة |
| ★ **الشاشات مالية كثيفة الأرقام** | ★ **الرقم غير المقروء = رقم خاطئ عملياً** |
| **أعمار وخبرات متفاوتة** | ★ **تكبير النص حاجة حقيقية لا خيار** |
| ★ **قرارات مالية فورية** | **الالتباس البصري يُنتج قراراً خاطئاً** |

## 2. ★ الحدود الملزمة

| البند | الحد |
|---|---|
| **تباين النص العادي** | ★ **4.5:1** |
| **النص الكبير** (≥18 أو ≥14 بوزن ثقيل) | ★ **3:1** |
| **عناصر الواجهة الدالّة** (حدود · أيقونات ذات معنى) | ★ **3:1** |
| ★ **هدف اللمس** | ★ **48×48 — بلا استثناء** |
| ★ **تكبير النص** | ★ **حتى 1.3× بلا كسر ولا قصّ** |
| **سماكة حلقة التركيز** | **2** |
| **أصغر حجم خط** | **12** |

| القاعدة |
|---|
| ★ **يُفحص التباين في الوضع الفاتح — وهو الوضع الوحيد** (`AM-003`) |
| ★ **على السطح الفعلي الذي يجلس عليه النص** — **بما فيه السطح الداكن للبطاقة الرئيسية** · ★ **وهذا سطحٌ داكن لا وضعٌ داكن** |

## 3. ★ المعنى دون لون — إلزامي

```text
★ لا يُنقَل أي معنى باللون وحده — أيقونة أو نص دائماً معه.
```

| الحالة | ما يصحبها |
|---|---|
| **حالة مستند (معتمَد · معلّق · ملغى)** | ★ **نص صريح + أيقونة** |
| **مبلغ مدين مقابل دائن** | ★ **إشارة أو تسمية — لا لون فقط** |
| **متبقٍّ متأخر** | ★ **وسم نصّي واضح** |
| **عنصر نشط في التنقّل** | **تغيّر شكل الأيقونة أيضاً لا لونها فقط** |

> ★ **اختبار الحياد:** ★ **لو حُذف اللون كله (تدرّج رمادي) — هل تبقى الشاشة
> مفهومة؟** ★ **إن لم تبقَ فالمعنى معلَّق على اللون، وهذا خلل يُصلَح لا ذوق
> يُناقَش.**

## 4. ★ الأرقام — قلب الإتاحة في هذا النظام

| # | القاعدة |
|---|---|
| 1 | ★ **أرقام جدولية في كل جدول وقائمة مالية** — ★ **تمنع اهتزاز الأعمدة** |
| 2 | ★ **كل رقم يمرّ عبر منسّق مركزي واحد** — ⛔ **لا تحويل مباشر في الشاشة** |
| 3 | ★ **الأرقام داخل نص عربي تُغلَّف بضبط اتجاه صريح** — ⛔ **وإلا انقلب ترتيبها** |
| 4 | ★ **تباين الأرقام المالية يجتاز 4.5:1 دائماً** |
| 5 | **المبالغ لا تُصغَّر لتوفير مساحة** — ★ **تُلَفّ أو يُعاد التخطيط** |

> ★ **رقم غير مقروء في نظام ذمم ليس مشكلة إتاحة بل مشكلة صحة.**

## 5. التركيز وقارئ الشاشة

| البند | القاعدة |
|---|---|
| **حلقة التركيز** | ★ **ظاهرة على كل عنصر تفاعلي** |
| **الحقل المركَّز** | حدّ أوضح **إضافةً** إلى الحلقة |
| ★ **ترتيب التركيز** | ★ **منطقي ويتبع اتجاه القراءة — ويُختبَر لا يُفترَض** |
| **الوصف الدلالي** | ★ **يذكر القيمة لا الفعل المجرَّد** — «إزالة الصنف س» لا «إزالة» |
| **الزخرفة** | ★ **مستبعَدة من القراءة** |
| **البطاقة** | ★ **تُقرأ وحدةً واحدة دون أن تبتلع أزرارها** |

## 6. ★ الحالات الأربع — إلزامية لكل قائمة وجدول

| الحالة | الشكل الواجب |
|---|---|
| **تحميل** | ★ **هيكل عظمي يحاكي شكل المحتوى القادم** — ⛔ **لا مؤشّر دوّار وسط الشاشة** |
| **فارغ** | **أيقونة + عنوان + شرح + إجراء** — ⛔ **لا «لا توجد بيانات» وحدها** |
| **خطأ** | **رسالة بشرية + سبب مختصر + إعادة محاولة** |
| **محتوى** | **مُختبَر ببيانات واقعية** |
| ★ **انقطاع الاتصال** | ★ **حالة خامسة إلزامية هنا** — النظام لا يعمل بلا اتصال |

## 7. الحركة والإجراءات المدمّرة

| البند | القاعدة |
|---|---|
| ★ **تقليل الحركة** | ★ **إعداد النظام محترَم — والحركة تُلغى لا تُبطَّأ** |
| **مدة الحركة** | ⛔ **لا تتجاوز 400ms · ولا ارتداد** |
| ★ **الإجراء المدمّر** | ★ **تأكيد صريح يذكر العنصر بالاسم** |

> ★ **ملاحظة خاصة:** ★ **لا حذف في هذا النظام أصلاً** — فالإجراءات المدمّرة
> هنا هي **الإلغاء بالوسم** و**التعديل المباشر**، ★ **وكلاهما يستلزم سبباً
> نصّياً وتأكيداً صريحاً.**

## 8. ما لا نلتزم به ولماذا

| البند | السبب |
|---|---|
| **دعم كامل لقارئ الشاشة بمستوى AAA** | ★ **AA هدف واقعي — والادعاء بما لا يُختبَر أسوأ من عدمه** |
| **دعم أجهزة إدخال متخصصة** | خارج نطاق الاستخدام الميداني |
| **الوضع عالي التباين المنفصل** | ★ **وضعٌ واحد (الفاتح) بتباين مضمون رياضياً في كل زوج** (`AM-003`) — ⛔ **ولا وضع ثانٍ يُفحَص ولا يُصان** |
