# قائمة فحص الإتاحة — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | **M** |
| **الطبيعة** | LIVING |
| **المالك** | DEV / QA |

> ★ **تُطبَّق على كل شاشة قبل الدمج** — وبنودها المنجَّمة ★ **حاجبة**.

---

## ① التباين

- [ ] ★ **كل نص عادي ≥ 4.5:1** على سطحه الفعلي
- [ ] **النص الكبير ≥ 3:1**
- [ ] **الحدود والأيقونات الدالّة ≥ 3:1**
- [ ] ★ **مفحوص في الوضع الفاتح — وهو الوضع الوحيد** (`AM-003`)
- [ ] ★ **النص فوق السطح الداكن للبطاقة الرئيسية يجتاز الحد** — ★ **أكثر المواضع تسرّباً**

## ② الأرقام — ★ خاص بهذا النظام

- [ ] ★ **أرقام جدولية في كل جدول وقائمة مالية**
- [ ] ★ **الأعمدة لا تهتزّ عند تغيّر القيم**
- [ ] ★ **كل رقم عبر المنسّق المركزي** — ⛔ لا تحويل مباشر
- [ ] ★ **الأرقام داخل نص عربي لا تنقلب**
- [ ] **المبالغ الطويلة تُلَفّ ولا تُقَصّ ولا تُصغَّر**

## ③ اللمس والحركة

- [ ] ★ **كل هدف قابل للنقر ≥ 48×48 فعلياً**
- [ ] **الرفع بحشو غير مرئي لا بتكبير الشكل**
- [ ] **الصف الواحد في الإدخال السريع هدف لمس واحد كبير**
- [ ] **تقليل الحركة محترَم — والحركة تُلغى لا تُبطَّأ**
- [ ] ⛔ **لا حركة تتجاوز 400ms ولا ارتداد**

## ④ التكبير والتخطيط

- [ ] ★ **تكبير النص 1.3× بلا كسر ولا قصّ**
- [ ] **لا ارتفاع صلب لأي صف نصّي**
- [ ] **الجداول تُمرَّر أفقياً ولا تُقَصّ**
- [ ] ★ **مُختبَر بأطول قيمة واقعية** — أطول اسم مقوت وأكبر مبلغ

## ⑤ المعنى دون لون

- [ ] ★ **كل حالة تحمل نصاً أو أيقونة — لا لوناً وحده**
- [ ] **المدين والدائن مميَّزان بإشارة أو تسمية**
- [ ] **المتبقي المتأخر موسوم نصّياً**
- [ ] **العنصر النشط في التنقّل يتغيّر شكله لا لونه فقط**
- [ ] ★ **اختبار الحياد: الشاشة مفهومة بالتدرّج الرمادي**

## ⑥ الحالات

- [ ] **تحميل: هيكل عظمي يحاكي المحتوى القادم** — ⛔ لا مؤشّر دوّار
- [ ] **فارغ: أيقونة + عنوان + شرح + إجراء**
- [ ] **خطأ: رسالة بشرية + سبب + إعادة محاولة**
- [ ] **محتوى: مُختبَر ببيانات واقعية**
- [ ] ★ **انقطاع الاتصال: تنبيه ظاهر + تعطيل الحفظ**

## ⑦ التركيز وقارئ الشاشة

- [ ] **حلقة تركيز ظاهرة على كل عنصر تفاعلي**
- [ ] ★ **ترتيب التركيز يتبع اتجاه القراءة — مُختبَر لا مفترَض**
- [ ] ★ **الوصف الدلالي يذكر القيمة** لا الفعل المجرَّد
- [ ] **الزخرفة مستبعَدة من القراءة**
- [ ] **البطاقة تُقرأ وحدةً دون ابتلاع أزرارها**

## ⑧ الاتجاه

- [ ] ⛔ **لا قيمة موضعية بـ«يمين/يسار»**
- [ ] **الأيقونات الاتجاهية تنعكس**
- [ ] **أشرطة التقدّم تتقدّم باتجاه القراءة**
- [ ] **أزرار الحوارات والأوراق تحترم الاتجاه**
- [ ] **حقول النص تبدأ من البداية الصحيحة**

## ⑨ النصوص

- [ ] ★ **لا مصطلح تقني في واجهة المستخدم**
- [ ] ★ **مصطلحات المجال من المعجم الموحَّد** — ⛔ **لا مرادفات**
- [ ] **رسالة الخطأ تقول ما الشرط المخالَف وكيف يُصلَح**
- [ ] **الزر يحمل فعلاً ومفعولاً** — لا «موافق»
- [ ] **التأكيد المدمّر يذكر العنصر بالاسم**

## ⑩ التوثيق

- [ ] **لقطة شاشة بالعربية RTL مرفقة بطلب الدمج**
- [ ] **الشاشة تنتمي لأحد أنماط التخطيط المعتمدة وصُرِّح بذلك**
