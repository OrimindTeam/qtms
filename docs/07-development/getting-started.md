## ⚠️ 1. اقرأ هذا أولاً — بوابة الدخول

> **لا يبدأ العمل على أي وحدة قبل اجتياز «الخطوة صفر»** (التأسيس التقني).
> راجع [`docs/01-product/product-roadmap.md`](../01-product/product-roadmap.md) §0.

**وثلاث قواعد لا تُخالَف في هذا المشروع:**

1. **الحماية في السحابة لا في الواجهة** — إخفاء الزر ليس حماية، والتحقق
   داخل كود التطبيق ليس حماية. **وأي قاعدة عمل بلا مقابل في قواعد الحماية
   تُعتبر غير مُنفَّذة أمنياً.**
2. **الحذف مرفوض نهائياً · وسجل التدقيق للإضافة فقط** — لكل المستخدمين
   **بمن فيهم المالك**.
3. ★ **كل مبلغ عدد صحيح بالريال (`int`)** — ⛔ **لا فاصلة عائمة ولا نوع
   عشري ولا تخزين بأصغر وحدة** (`ADR-0015`) · **ولا تُجمع الحبات مع
   الأوزان · ولا يُخلَط `stockDate` بـ`entryDate`.**

*التفصيل: [`environment-setup.md`](environment-setup.md).*

## 3. الخطوات

```bash
# 1) استنساخ المستودع
git clone <رابط المستودع>
cd qtms

# 2) تنزيل الاعتماديات
flutter pub get

# 3) ربط المشروع بالبيئة التجريبية  (⚠️ لا الإنتاجية أبداً)
#    التجريبي: qtms-orimind-master   (⛔ لا qtms-orimind-c001)

# 4) تشغيل المحاكي المحلي للمنصة (لاختبار قواعد الحماية)
#    راجع build-and-run-instructions.md

# 5) التشغيل
flutter run
```

> ⚠️ **لا تربط بيئتك المحلية بمشروع الإنتاج إطلاقاً.** بيانات هذا النظام
> **ذمم ومخزون حقيقية** — وخطأ واحد في بيئة خاطئة يُفسِد حسابات فعلية.
