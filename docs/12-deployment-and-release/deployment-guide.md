## 1. ★ الترتيب الملزم — لا يُخالَف

```text
① الفهارس            ⟵ ★ أولاً دائماً · وبناؤها يستغرق وقتاً
② قواعد الحماية       ⟵ ★ قبل الكود الذي يعتمد عليها
③ العمليات السحابية   ⟵ قبل الواجهة التي تستدعيها
④ التطبيق            ⟵ أخيراً
```

| مخالفة الترتيب | النتيجة |
|---|---|
| **التطبيق قبل القواعد** | ★ **نافذة زمنية بلا حماية** |
| **التطبيق قبل الفهارس** | **استعلامات تفشل أو تُكلّف** |
| **التطبيق قبل العمليات** | **استدعاء عملية غير موجودة** |
| **القواعد قبل الفهارس** | استعلامات القواعد نفسها قد تتأثر |

## 3. ★ توقيت النشر

> ★ **لا تنشر في ذروة الاستخدام اليومي.** النشاط **موسمي مركَّز في ساعات
> محدودة**، ونشرٌ في تلك الساعات **يوقف عملاً حقيقياً بلا بديل** — إذ **لا
> عمل دون اتصال في هذا النظام**.

| القاعدة |
|---|
| ★ **خارج ساعات الذروة** |
| ★ **لا نشر إنتاجي بلا حضور من يستطيع التراجع** |
| ⛔ **لا نشر قبل عطلة بلا متابعة** |

## 4. ★ إجراء الترحيل البنيوي

> **عند وجود تغيير في بنية القاعدة:**

```text
① سطر في migrations-log.md ضمن نفس الدمج
② ★ جُرِّب على المحاكي ثم التجريبية ببيانات مشابهة
③ ★ نسخة احتياطية قبل النشر الإنتاجي مباشرة
④ ⛔ لا إعادة تسمية حقل ولا تغيير معناه — إضافة فقط
⑤ التحقق بعد النشر: عيّنة مستندات قديمة تُقرَأ بمعناها الأصلي
```

## 6. توزيع الحزمة

| المسار | ملاحظة |
|---|---|
| **متجر التطبيقات** | مراجعة المتجر + تحديث تدريجي |
| ★ **التوزيع المباشر** | ★ **لا تحديث تلقائي — تنبيه داخل التطبيق للإصدار الإلزامي** |

| القاعدة |
|---|
| ★ **نفس شهادة التوقيع دائماً** — تغييرها يمنع التحديث فوق المثبَّت |
| **إشعار المستخدمين بالتغييرات المؤثرة على سير العمل** |
