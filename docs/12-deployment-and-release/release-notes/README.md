# ملاحظات الإصدار — QTMS

| البند | القيمة |
|---|---|
| **الطبيعة** | LOG |
| **المالك** | DEV / PO |
| **الحالة** | ⏳ **لا إصدارات — لم يبدأ التنفيذ** |

---

## 1. التسمية

```text
v<MAJOR>.<MINOR>.<PATCH>.md        مثال: v1.0.0.md
```

## 2. الفرق بينها وبين `changelog.md`

| `changelog.md` | ملاحظات الإصدار |
|---|---|
| **سجل تراكمي مختصر** | ★ **رسالة كاملة لإصدار واحد** |
| قوائم مصنَّفة | ★ **سرد يشرح الأثر على العمل اليومي** |
| للمرجع | ★ **تُقرأ عند التحديث** |

## 3. ★ القالب

```markdown
# الإصدار v<X.Y.Z> — <التاريخ>

## ما الجديد
## ★ ما تغيّر في طريقة العمل   ← الأهم للمستخدم
## ما أُصلح
## ★ تغييرات تمسّ أرقاماً       ← ★ إلزامي إن وُجدت
## ★ هل يلزم التحديث فوراً؟     ← إلزامي / مُوصى به
## ما يحتاج انتباهاً
```

## 4. ★ قواعد الكتابة

| # | القاعدة |
|---|---|
| 1 | ★ **بالعربية وبلغة العمل لا لغة الكود** |
| 2 | ★ **كل تغيير يمسّ رقماً مالياً يُذكر بوضوح شديد** — **حتى لا يفاجأ المالك برقم مختلف** |
| 3 | ★ **التحديث الإلزامي يُعلَن صراحةً** — التوزيع المباشر بلا تحديث تلقائي |
| 4 | **ما يستلزم تغيير عادة يومية يُشرَح خطوة بخطوة** |
| 5 | ⛔ **لا تفاصيل أمنية قابلة للاستغلال** |
