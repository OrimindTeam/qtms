# قائمة تحقق الإصدار — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | **M** |
| **الطبيعة** | LIVING |
| **المالك** | DEVOPS / QA |

> **تُنسَخ وتُملأ لكل إصدار.** ★ **بند واحد غير محقَّق ⟵ لا نشر.**

---

## ① الجودة

- [ ] كل الاختبارات الآلية تمرّ
- [ ] ★ **اختبارات قواعد الحماية تمرّ على المحاكي**
- [ ] ★ **تغطية طبقة المجال 100٪**
- [ ] ★ **السيناريو المرجعي (§15) متوازن بالكامل**
- [ ] لا خلل حاجب أو حرج مفتوح
- [ ] الفحص الساكن نظيف

## ② الأمن

- [ ] ★ **كل سطر في جدول التتبع له مقابل مُختبَر**
- [ ] ★ **اختبارات المنع الاثنا عشر تمرّ** ([`../08-testing-and-qa/security-testing-plan.md`](../08-testing-and-qa/security-testing-plan.md) §3)
- [ ] ⛔ **لا سرّ في الحزمة ولا في المستودع**
- [ ] لا ثغرة حرجة في الاعتماديات
- [ ] ★ **اختبار تجاوز الواجهة يُرفَض**

## ③ البيانات

- [ ] سطر في [`../06-database/migrations-log.md`](../06-database/migrations-log.md) إن مُسَّت البنية
- [ ] ★ **`stockDate` موجود في النموذج وكل فهرس** (`RISK-01`)
- [ ] ★ **نسخة احتياطية حديثة قبل النشر**
- [ ] الفهارس الجديدة جاهزة للنشر أولاً

## ④ الأداء والكلفة

- [ ] ★ **كل استعلام جديد له فهرس**
- [ ] ★ **عدد القراءات لكل شاشة جديدة مقيس وموثَّق**
- [ ] لا استعلام داخل حلقة
- [ ] القوائم الطويلة مُرقَّمة

## ⑤ الواجهة والإتاحة

- [ ] ★ **عربية RTL بالكامل**
- [ ] ★ **أرقام جدولية متحاذية في كل جدول مالي**
- [ ] تكبير النص 1.3× بلا كسر
- [ ] التباين ≥ 4.5:1 · مساحة اللمس ≥ 48×48
- [ ] الحالات الأربع مغطّاة
- [ ] ★ **حالة انقطاع الشبكة تعمل — ولا وهم حفظ**
