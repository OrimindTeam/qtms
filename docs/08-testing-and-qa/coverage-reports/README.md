## 1. المحتوى

**تقارير التغطية المولَّدة آلياً** — تُحفَظ بتاريخها:

```text
coverage-<YYYY-MM-DD>.md   أو مخرجات الأداة الخام
```

## 2. الأهداف

| النطاق | الهدف |
|---|---|
| ★ **طبقة المجال (المعادلات)** | ★ **100٪** |
| ★ **قواعد الحماية** | ★ **كل قاعدة: سماح + منع** |
| العمليات السحابية | ≥ 80٪ 🔶 |
| مجمل المشروع | ≥ 70٪ 🔶 |

> 🔶 = افتراض قياسي أضفناه — المصدر لم يحدد نسباً.

## 3. ⚠️ حدود قراءة النسبة

> **النسبة مؤشّر لا حكم.**
>
> | المغالطة | الحقيقة |
> |---|---|
> | «100٪ تغطية ⟵ الكود صحيح» | ★ **تغطية بمتوقَّعات منسوخة من مخرج الكود تساوي صفراً** |
> | «سطر مُغطّى ⟵ سلوك مُختبَر» | **التغطية تقيس التنفيذ لا التحقق** |
> | «رفع النسبة هدف» | **المعيار الحقيقي: هل المتوقَّع مصدره المستند؟** |
