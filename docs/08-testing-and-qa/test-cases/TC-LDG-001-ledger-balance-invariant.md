# TC-LDG-001 — ★ ثابت التوازن: الرصيد = مجموع الحركات

| البند | القيمة |
|---|---|
| **المستوى** | وحدة + تكامل |
| **الأولوية** | 🔴 **حرجة — أقوى شبكة أمان في النظام** |
| **يغطّي** | ★ **`ADR-0008`** · الدفاتر الأربعة |
| **النوع** | ✅ إثبات (ثابت دائم) |

---

## 1. المبدأ

```text
★ لكل دفتر · وفي كل لحظة · وبعد كل عملية:

        الرصيد المعروض  ==  مجموع حركات دفتره

★ ولا استثناء واحد — والملخص لا يُقرأ أبداً كمصدر حقيقة.
```

## 2. النطاق

| الدفتر | الرصيد المُتحقَّق منه |
|---|---|
| **المخزون** | رصيد النوع في اليوم |
| **المقاوته** | باقي ضمار المقوت |
| **الرعية** | حساب الرعوي |
| **السحبيات** | مجموع السحبيات والخرجيات |

## 3. الخطوات

```text
① نفّذ أي عملية تكتب في دفتر
② اقرأ الرصيد المعروض
③ اقرأ كل حركات الدفتر المقابلة
④ قارن
```

## 4. ★ التطبيق الملزم

> **اجعل هذا تأكيداً مشتركاً (helper) يُستدعى في نهاية كل اختبار تكامل
> يمسّ الدفاتر** — لا حالة اختبار منفصلة تُنسى.

**ويُختبَر بعد كل من:**

| العملية |
|---|
| توزيع · اعتماد توزيعة |
| قبض · خصم |
| بيع نقدي |
| سحبية · خرجية |
| ★ **تعديل مباشر لحركة معتمَدة** |
| ★ **تصفية متبقٍّ متأخر** |
| ★ **إعادة بناء الملخصات** |

## 5. اختبار الخصائص (مُوصى به بشدة)

```text
لأي تسلسل عشوائي من العمليات الصحيحة:
        ★ الثابت يبقى صحيحاً
```

> **هذا يكشف ما لا تكشفه الحالات المكتوبة يدوياً** — خصوصاً **تسلسلات
> العمليات غير المتوقَّعة** التي تحدث في الاستخدام الحقيقي.

## 6. معيار النجاح

- [ ] **الثابت صحيح بعد كل عملية في §4**
- [ ] ★ **إعادة بناء الملخصات لا تُغيّر أي رصيد** — تُعيد إنتاج نفس القيمة
- [ ] ★ **تشغيل إعادة البناء مرتين = نفس النتيجة** (idempotent)
- [ ] **الوحدات محفوظة** — لا حبات مجموعة مع أوزان

## 7. عند الفشل

> ⛔ **فشل هذا الاختبار = خلل حاجب تلقائياً.**
>
> **الأسباب المرجّحة:** تراكم بدل إعادة بناء · قراءة من ملخص كمصدر حقيقة ·
> حركة كُتبت خارج المعاملة · فاصلة عائمة.
