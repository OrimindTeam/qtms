# TC-FIN-001 — ★ السيناريو المرجعي لليوم الكامل

| البند | القيمة |
|---|---|
| **المستوى** | تكامل + قبول |
| **الأولوية** | 🔴 **حرجة — اختبار الانحدار المالي الرئيسي** |
| **يغطّي** | **معظم `GR-*` · الدفاتر الأربعة · بطاقة ضمار المالك** |
| **النوع** | ✅ إثبات |
| **المصدر** | ★ **§15 من المستند المصدر — سيناريو يوم كامل محسوب ومتوازن** |

---

## 1. لماذا هذه الحالة استثنائية

> ★ **هذا هو الاختبار الوحيد الذي يمسّ النظام كله دفعة واحدة بأرقام
> يقينية.** المصدر نفسه حسبها ووازنها — **فأي انحراف عنها خللٌ في الكود
> لا في التوقّع**.

**تُشغَّل بعد أي تغيير يمسّ معادلة — بلا استثناء.**

## 2. التمهيد

| البند | القيمة |
|---|---|
| **البيانات** | ★ **مجموعة §15 الثابتة** (`DEBT-06`) — بيانات وهمية |
| **البيئة** | المحاكي المحلي أو التجريبية |
| **الحالة الابتدائية** | ★ **نظيفة معلومة** — لا بقايا من تشغيل سابق |
| **الزمن** | ★ **محقون** — لا ساعة نظام |

## 3. الخطوات

```text
① استلام الجواني بأوزانها ورعاتها
② تسعير الأنواع لليوم
③ التوزيع على المقاوته  (⚠️ توزيعة واحدة لكل مقوت في المصدر — GR-18)
④ اعتماد التوزيعات
⑤ البيع النقدي
⑥ تسجيل المقبوضات
⑦ تسجيل الخصومات
⑧ تسجيل السحبيات والخرجيات
⑨ إقفال اليوم وبناء الملخصات
```

## 5. ✅ `OQ-001` — محسوم · والأرقام المتوقَّعة محدَّثة

★ **القيم المتوقَّعة الملزمة لهذا الاختبار (رداع · 20/08):**

| البند | ★ القيمة المتوقَّعة | الاشتقاق |

> ما كشف التعارض أصلاً، فيبقى اختباراً دائماً.**
