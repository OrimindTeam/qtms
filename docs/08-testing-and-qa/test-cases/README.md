## 3. ★ قواعد ملزمة

| # | القاعدة |
|---|---|
| 1 | ★ **كل رقم متوقَّع يذكر مرجعه في المستند المصدر** |
| 2 | ★ **لكل `GR-*` حالة إثبات وحالة نفي** — الإثبات وحده لا يُثبت أن المخالفة ممنوعة |
| 3 | **كل `E-*` لها حالة اختبار** |
| 4 | **كل `AT-*` مغطّاة آلياً أو في القبول** |
| 5 | ⛔ **لا بيانات إنتاجية** |
