# TC-AUD-001 — ★★ التعديل المباشر يستلزم صلاحيةً وقيد تدقيق

| البند | القيمة |
|---|---|
| **المستوى** | تكامل |
| **الأولوية** | 🔴 **حرجة** |
| **يغطّي** | ★ **`A-14` — التعديل المباشر بلا قيود عكسية** · `ADR-0004` · ★★ **`ADR-0020`** (2026-08-27) |
| **النوع** | ✅ إثبات + ⛔ نفي |

---

## 1. المبدأ

```text
★ لا قيود تصحيحية ولا عكسية في هذا النظام.
   الحركة تُعدَّل في مكانها — بشرطين لا يُخترَقان (كانا ثلاثة):
        ① صلاحية صريحة
        ② ★ قيد تدقيق مفروض — وفشله يُلغي التعديل كله
   ⛔ والشرط «سبب نصّي إلزامي» أُلغي بـADR-0020 (2026-08-27):
      السبب اختياريٌّ في كل العمليات، ولا يُعبَّأ آلياً أبداً.
```

## 2. الجزء ✅ — التعديل المشروع

```text
① مستخدم مخوَّل يعدّل حركة معتمَدة
② يُدخل سبباً نصّياً — ★ اختيارياً (وتُختبَر الحالتان: بسبب وبلا سبب)
③ يُحفظ التعديل
```

**المتوقَّع:**

| # | البند |
|:-:|---|
| 1 | **الحركة عُدّلت في مكانها** — ⛔ **ولا قيد عكسي أُنشئ** |
| 2 | ★ **قيد تدقيق يحوي: القيمة قبل · القيمة بعد · المستخدم · الزمن** ★★ **والسبب إن كتبه المستخدم** — ⛔ **وإلا فحقلٌ غائب** ⛔ **لا نصٌّ مُعبَّأ آلياً** |
| 3 | ★ **`amendSequence` تزايد** في سجل تعديلات المستند |
| 4 | ★ **الأرصدة والملخصات المتأثرة أُعيد بناؤها** |
| 5 | ★ **ثابت التوازن ما زال صحيحاً** |
| 6 | **المستند موسوم كمُعدَّل — والتعديل ظاهر للمستخدم لا مخفي** |

## 3. الجزء ⛔ — ما يجب أن يُرفَض

| # | المحاولة | الواجب |
|:-:|---|:-:|
| ~~1~~ | ~~**تعديل بلا سبب نصّي**~~ | ✅★★ **يُقبَل الآن** — `ADR-0020` |
| 2 | ★★ **تعديل بسبب فارغ أو مسافات فقط** | ✅ **يُقبَل — والحقل يُخزَّن غائباً لا فراغات** |
| 3 | **تعديل بلا صلاحية** | ⛔ رفض |
| 4 | ★ **تعديل قيد تدقيق سابق** | ⛔ رفض |
| 5 | ★ **مسح قيد تدقيق** | ⛔ رفض |
| 6 | **تعديل مباشر متجاوِزاً الواجهة** | ⛔ رفض |
| 7 | **تعديل حركة في مستند ملغى** | ⛔ رفض |

## 4. ★ اختبار الذرّية — الأهم

```text
① اجعل كتابة قيد التدقيق تفشل (محاكاة)
② نفّذ تعديلاً مشروعاً تماماً
③ ★ المتوقَّع: التعديل كله يُلغى — والحركة تبقى كما كانت بالضبط
```

> ★ **هذا جوهر `ADR-0004`:** التعديل المباشر **مقبول فقط لأن سجل التدقيق
> يحفظ التاريخ**. **فتعديل بلا قيد تدقيق يهدم المبرر كله** — ولا يُقبل
> «التعديل نجح والقيد فشل» بأي حال.

- [ ] ★ **اختبار الذرّية في §4 ناجح — لا أثر جزئي إطلاقاً**
