# TC-TIME-001 — ★ تصفية المتبقي المتأخر وإعادة البناء بأثر رجعي

| البند | القيمة |
|---|---|
| **المستوى** | تكامل + E2E |
| **الأولوية** | 🔴 **حرجة — أعقد سلوك زمني في النظام** |
| **يغطّي** | ★ **ازدواج التاريخ** (`stockDate` / `entryDate`) · إعادة البناء بأثر رجعي |
| **النوع** | ✅ إثبات |

---

## 1. المبدأ

```text
★ التاريخان ليسا مترادفين:
     stockDate  = يوم المحاسبة        ← ★ كل التقارير المخزنية تُبنى عليه
     entryDate  = لحظة التسجيل الفعلي  ← ★ للتدقيق فقط · ولا يُفهرَس مخزنياً

★ وهما يختلفان فقط عند تصفية متبقٍّ متأخر.
```

## 2. التمهيد

| البند | القيمة |
|---|---|
| **اليوم الأول** | حركات تترك **رصيداً غير مُصفّى** |
| **إقفال اليوم الأول** | تُبنى ملخصاته |
| **اليوم التالي (أو بعده)** | ★ **تُصفّى بقية اليوم الأول** |
| **الزمن** | ★ **محقون — لا ساعة نظام** |

## 3. الخطوات

```text
① اليوم الأول: حركات تترك متبقياً
② أقفل اليوم الأول واحفظ ملخصاته المرجعية
③ في يوم لاحق: صفِّ المتبقي
        ⟵ stockDate = ★ اليوم الأول   (يوم المحاسبة)
        ⟵ entryDate = ★ اليوم اللاحق  (لحظة التسجيل)
④ اقرأ ملخصات اليوم الأول مجدداً
```

## 4. ★ المتوقَّع

| # | البند |
|:-:|---|
| 1 | ★ **الحركة تُنسَب لليوم الأول في كل تقرير مخزني** — لا لليوم اللاحق |
| 2 | ★ **ملخصات اليوم الأول أُعيد بناؤها** لتشمل التصفية |
| 3 | ★ **الملخص المُعاد بناؤه موسوم «⟳ مُحدَّث بأثر رجعي»** |
| 4 | ★ **`entryDate` محفوظ كما هو** — ويظهر في سجل التدقيق فقط |
| 5 | **رصيد اليوم الأول صار مُصفّى** |
| 6 | ★ **ملخصات اليوم اللاحق لم تتأثر** — الحركة ليست حركته |
| 7 | **قيد في سجل التدقيق يوثّق التصفية بتاريخيها** |
| 8 | ★ **ثابت التوازن ما زال صحيحاً** (`TC-LDG-001`) |

## 5. حالات النفي المرافقة

| # | يجب أن يُرفَض أو يُمنَع |
|:-:|---|
| 1 | ★ **بناء تقرير مخزني على `entryDate`** |
| 2 | **تصفية متبقٍّ بتاريخ محاسبة مستقبلي** |
| 3 | **تصفية أكثر من المتبقي فعلاً** |

## 6. معيار النجاح

- [ ] **كل بنود §4 متحققة**
- [ ] ★ **إعادة تشغيل إعادة البناء لا تُغيّر النتيجة** (idempotent)
- [ ] **بنود §5 ممنوعة فعلياً**
- [ ] **لا خلط بين التاريخين في أي شاشة أو تقرير**

## 7. ⚠️ خطر مرتبط

> ★ **`RISK-01`:** إن بُنيت المرحلة الأولى بلا حقل `stockDate` أصلاً، فهذا
> السلوك **يستحيل تنفيذه لاحقاً بلا هجرة كاملة لبيانات مالية حيّة**.
> **الحقل إلزامي في النموذج وكل فهرس منذ اليوم الأول** — وهو **بند قبول في
> مراجعة المعلم `M-1`**.
