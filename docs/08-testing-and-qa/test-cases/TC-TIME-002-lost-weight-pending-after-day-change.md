# TC-TIME-002 — ⏳ توقيتُ بند «الوزن الضائع لم يُؤكَّد» في المركز المعلّق

| البند | القيمة |
|---|---|
| **المستوى** | نطاق + تكامل (الطرف السحابي) |
| **الأولوية** | 🟠 **عالية — سلوكٌ زمنيٌّ يغيّر ما يراه المستخدم في «يحتاج تصرفاً»** |
| **يغطّي** | `FR-M7-19` · `E-10` · `CR-013` · `OQ-002` (الخيار ب) · `pending-entries-design.md` §12.2-أ |
| **النوع** | ✅ إثبات + ⛔ نفي |

---

## 1. المبدأ

```text
★ شرطان مجتمعان لا أحدهما:
     ① الحالة  = SackWeightState.unexplained   ← وزنٌ متبقٍّ لم يُؤكَّد ضائعاً
     ② التوقيت = stockDate  <  platformToday   ← ★ تغيّر تاريخُ المخزون

⛔ ولا مهلةَ زمنية ولا رقمَ ساعات — الحدُّ هو تغيّرُ اليوم التقويمي نفسُه.
⛔ ولا مسارَ كتابةٍ مجدول — البند يُكتب في معاملة مستنده (§12.2).
```

★ **والدالةُ الحاكمة واحدة:** `isSackLostWeightDue(stockDate:, today:)`
⛔ **ولا نسخةَ ثانية من الشرط في السحابة ولا في الشاشة.**

## 2. التمهيد

| البند | القيمة |
|---|---|
| **الجونية** | لها أوزانٌ مطالبٌ بها، **وضريبتُها وأنواعُها مُدخَلة** — ⟵ **فالحقلُ المرشَّح الوحيد هو «الوزن الضائع»** |
| **المتبقي** | **موجبٌ فوق الهامش** (مثلاً 3.500 كجم) و`lostWeightConfirmed = false` |
| **الزمن** | ★ **محقونٌ صراحةً** (`platformToday`) — ⛔ **لا ساعةُ نظامٍ ولا ساعةُ حاوية** (`GR-54`) |

## 3. الخطوات

```text
① جونية تاريخُ مخزونها D ــ يُدخَل أوّلُ سطرِ أنواع ويبقى وزنٌ غير مفسَّر
        ⟵ platformToday = D
② نفسُ الحالة بلا أي تغييرٍ في البيانات
        ⟵ platformToday = D + 1
③ نفسُ الحالة ويومُ المنصّة لم يصل
        ⟵ platformToday = غيرُ معلوم
④ جونية بلا ضريبةٍ ولا أنواعٍ ومعها وزنٌ غير مفسَّر
        ⟵ platformToday = D
```

## 4. ★ المتوقَّع

| # | الخطوة | البند |
|:-:|:-:|---|
| 1 | ① | ⛔ **لا بندَ `sackLostWeight` يُكتَب** — ★ **ومعرّفُه في `clearedIds` فيُمحى بندٌ كُتب بالسلوك القديم** |
| 2 | ② | ✅ **البندُ يُكتَب** بنصِّه ودلالته ⏳ **البرتقالية كما هي** (§4) |
| 3 | ③ | ⛔ **تأجيلٌ لا ظهورٌ بالشكّ** — ★ **نظيرُ `isAgedRemainder` حرفياً** |
| 4 | ④ | ✅ **بندا «ضريبة الكيلو» و«الأنواع لم تُدخل» يظهران فوراً** (`E-06` كما هو) ⛔ **ولا ثالثَ معهما** |
| 5 | ①..④ | ★ **المجموعتان متكاملتان دائماً**: `drafts + clearedIds` = **ثلاثة حقول** بالضبط |
| 6 | ②→② | ★ **تشغيلٌ مكرَّرٌ يُنتج الحصيلةَ نفسَها حرفياً** (`PAT-07`) |

## 5. حالات النفي المرافقة

| # | يجب أن يُرفَض أو يُمنَع |
|:-:|---|
| 1 | ⛔ **تمريرُ `stockDate` مكان يومِ المنصّة** — ★ **يُلغي الشرطَ بصمت ويعيد السلوك القديم** |
| 2 | ⛔ **قراءةُ ساعةِ الحاوية أو ساعةِ الجهاز** بدلاً من `platformDayOf` |
| 3 | ⛔ **تأجيلُ «ضريبة الكيلو» أو «الأنواع لم تُدخل»** — ★ **الشرطُ لحقلٍ واحد** |
| 4 | ⛔ **تخفيفُ الدلالة البصرية** بدل التأجيل (`OQ-002` الخيار د — **مرفوض**) |
| 5 | ⛔ **مهلةٌ بالساعات** أو أيُّ رقمٍ مخترَع (`OQ-002` الخيار ج — **مرفوض**) |
| 6 | ⛔ **تسجيلُ الوزن ضائعاً تلقائياً بمرور اليوم** — ★ **`BR-M7-12` لم يُمَسّ: الزرُّ الصريح وحده** |

## 6. معيار النجاح

- [ ] **كل بنود §4 متحققة**
- [ ] **بنود §5 ممنوعة فعلياً**
- [ ] ★ **ولا رقمَ مالياً تغيّر** — سعرُ الجونية والضريبةُ وصافي الرعوي كما هي
- [ ] ★ **و`firestore.rules` لم تُمَسّ** — `pending_entries` **`allow write: if false`**
