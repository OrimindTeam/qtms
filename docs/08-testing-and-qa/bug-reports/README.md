## 1. التسمية

```text
BUG-<رقم متسلسل>-<وصف-مختصر>.md      مثال: BUG-001-dealer-balance-mismatch.md
```

## 2. القالب الأدنى

```markdown
# BUG-<رقم> — <العنوان>

| البند | القيمة |
|---|---|
| **الشدّة** | ⛔ حاجب / 🔴 حرج / 🟠 مهم / 🟡 بسيط |
| **الوحدة** | <اسم الوحدة> |
| **البند المرجعي** | FR-M* · GR-* · E-* · AT-* |
| **الحالة** | مفتوح / قيد المعالجة / مُصلَح / مُغلَق |
| **البيئة** | تجريبية / محاكي / إنتاج |

## الخطوات
①  ②  ③

## المتوقَّع  (★ من المستند لا من الكود)
## الفعلي
## الأثر المالي   ← ★ إلزامي إن مسّ رقماً
## المرفقات       ← لقطة شاشة بالعربية RTL
```

## 3. ★ قواعد

| # | القاعدة |
|---|---|
| 1 | ★ **كل خلل مالي حاجب تلقائياً** — مهما بدا الفرق صغيراً |
| 2 | ★ **المتوقَّع يُشتقّ من المستند المصدر** لا من سلوك الكود |
| 3 | ⛔ **لا بيانات حقيقية في المرفقات** — أخفِ أو أعد الإنتاج ببيانات وهمية |
| 4 | ★ **لا يُغلَق خلل بلا اختبار يُثبت زواله** — ويبقى ذلك الاختبار دائماً |
| 5 | ⛔ **الثغرات الأمنية لا تُوثَّق هنا** — راجع [`../security-testing-plan.md`](../security-testing-plan.md) §8 |
