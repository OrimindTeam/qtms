## 1. لماذا الأداء مهم هنا تحديداً

| السبب | الأثر |
|---|---|
| ★ **لا تخزين مؤقت محلي** | **كل قراءة تذهب للسحابة فعلاً** — لا شبكة أمان |
| ★ **الاستخدام موسمي مركَّز** | **ذروة يومية في ساعات محدودة** لا حمل موزَّع |
| ★ **التكلفة بالقراءة/الكتابة** | **الاستعلام الثقيل يُكلّف مالاً لا وقتاً فقط** |
| **شبكات ميدانية متفاوتة** | التحسين لا يُقاس على شبكة مكتب |

## 3. المقاييس

| المقياس | الهدف | الحالة |
|---|---|---|
| **زمن فتح الشاشة الرئيسية** | ⏳ | **يُحدَّد بعد قياس أول نسخة** |
| **زمن حفظ توزيعة** | ⏳ | — |
| **زمن أثقل تقرير** | ⏳ | — |
| **عدد القراءات لكل شاشة** | ★ **يُقاس ويُوثَّق** | **الكلفة مقياس أول درجة هنا** |
| **زمن الإقلاع البارد** | ⏳ | — |

> رقماً مخترعاً يُبرَّر لاحقاً بدل أن يُوجّه.

## 4. ★ اختبار النمو — الأهم

> **النظام لا ينهار في اليوم الأول بل في الشهر الثاني عشر.**

| البُعد | ما يُختبَر |
|---|---|
| **حجم الدفاتر** | أداء الاستعلامات بعد **سنة بيانات محاكاة** |
| ★ **سجل التدقيق** | **ينمو بلا حد** — يجب ألا يُبطئ أي شاشة |
| **عدد المصادر** | أداء التقارير عبر مصادر متعددة |
| **عدد أيام المتبقي المتأخر** | ★ **أخطر بُعد نمو** — القائمة المبنية مسبقاً ضرورية |

## 5. ★ مضادات الأداء — ترصدها الاختبارات

| المضاد | الأثر |
|---|---|
| **استعلام بلا فهرس** | **مسح كامل — بطء وكلفة** |
| **قراءة الدفتر كله لحساب رصيد في الواجهة** | **يجب أن يُقرأ من الملخص الجاهز** |
| **استعلام داخل حلقة** (N+1) | **انفجار عدد القراءات** |
| **قراءة سجل التدقيق كاملاً** | **ينمو بلا حد** |
| **بناء تقرير من الدفاتر بدل الملخصات** | نفس السبب |
| **جلب مستندات كاملة لعرض حقل واحد** | كلفة نقل بلا مقابل |

## 6. الأدوات والدورة

| البند | القيمة |
|---|---|
| **القياس** | أدوات قياس أداء الإطار + عدّادات القراءة/الكتابة السحابية |
| **الجهاز المرجعي** | ★ **جهاز متوسط أو ضعيف** — لا جهاز التطوير |
| **الشبكة المرجعية** | ★ **شبكة بطيئة محاكاة** — لا واي-فاي مكتب |
| **الدورة** | **قبل كل إصدار** + **عند كل تقرير جديد** |
