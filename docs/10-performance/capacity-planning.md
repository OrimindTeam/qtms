# تخطيط السعة — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | O |
| **الطبيعة** | LIVING |
| **المالك** | DEVOPS |

> ★ **في هذه المنصة، السعة والتكلفة وجهان لشيء واحد:** لا خوادم تُحجَز،
> **بل قراءات وكتابات تُحاسَب عليها**. **فتخطيط السعة هنا تخطيط تكلفة.**

---

## 1. محرّكات النمو

| المحرّك | الأثر | الخطورة |
|---|---|---|
| **عدد المصادر** | يضاعف كل شيء تقريباً | 🟠 |
| **عدد المقاوته لكل مصدر** | حركات ومديونيات يومية | 🟠 |
| **عدد الجواني اليومية** | حركات مخزون وأنواع | 🟠 |
| ★ **عدد الأيام (الزمن)** | ★ **نمو خطّي لا يتوقف** | 🔴 |
| ★ **سجل التدقيق** | ★ **الأسرع نمواً — قيد لكل عملية حسّاسة** | 🔴 |
| **عدد المستخدمين المتزامنين** | ذروة القراءات | 🟠 |

## 2. ★ أنماط الاستهلاك

| النمط | ملاحظة |
|---|---|
| ★ **ذروة يومية مركَّزة** | **الاستخدام موسمي بطبيعة النشاط** — لا حمل موزَّع |
| ★ **قراءة أكثف من الكتابة بكثير** | شاشات ولوحات وتقارير |
| ★ **لا تخزين مؤقت محلي** | ★ **كل فتح شاشة = قراءات فعلية جديدة** |
| **الكتابة مركَّزة في المعاملات** | اعتماد التوزيع أثقل عملية كتابة |

## 3. ★ ضوابط الكلفة

| # | الضابط | الأثر |
|:-:|---|---|
| 1 | ★ **التقارير من الملخصات لا الدفاتر** | **يقلّص القراءات بمقدار كبير** |
| 2 | ★ **قائمة المتبقي المتأخر مبنية مسبقاً** | يمنع مسح الأيام السابقة |
| 3 | ★ **ترقيم الصفحات في كل قائمة** | يمنع الجلب الكامل |
| 4 | ★ **فهرس لكل استعلام** | **الاستعلام بلا فهرس مسح كامل مكلف** |
| 5 | **جلب الحقول اللازمة فقط** | كلفة نقل |
| 6 | ★ **إعادة بناء الملخصات مُشغَّلة بحدث لا بجدولة كثيفة** | كتابات بلا داعٍ |
| 7 | ★ **لا فهرس بلا استعلام** | **كل فهرس يزيد كلفة الكتابة** |

## 4. ★ سجل التدقيق — البند الأخطر على المدى الطويل

> **ينمو بلا حد بطبيعته** — ولا يجوز تقليمه لأنه **الحافظ الوحيد للتاريخ**
> بعد `ADR-0004`.

| الضابط |
|---|
| ★ **لا يُقرأ كاملاً في أي شاشة إطلاقاً** |
| **فهرسة ضيقة ومحدَّدة الغرض** |
| **ترقيم صفحات دائم** |
| ★ **الأرشفة الباردة تُدرَس لاحقاً — ⛔ ولا حذف** |

## 5. المراقبة

| المؤشّر | الدورة | الغرض |
|---|---|---|
| **إجمالي القراءات والكتابات** | **شهرياً** | `NFR-COST-03` |
| ★ **أكثر الاستعلامات استهلاكاً** | **شهرياً** | كشف المسح الكامل |
| **حجم البيانات** | شهرياً | توقّع النمو |
| **حجم سجل التدقيق** | شهرياً | ★ **الأسرع نمواً** |
| **استدعاءات العمليات السحابية** | شهرياً | كشف التكرار غير الضروري |
