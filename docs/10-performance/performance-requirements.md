## 1. ★ القيود التي تحكم الأداء هنا

| القيد | الأثر |
|---|---|
| ★ **لا تخزين مؤقت محلي** (`ADR-0003`) | ★ **كل قراءة تذهب للسحابة فعلاً — لا شبكة أمان** |
| ★ **لا عمل دون اتصال** | **الشبكة البطيئة تعني نظاماً بطيئاً — لا نظاماً معطّلاً** |
| ★ **الكلفة بالقراءة والكتابة** | ★ **الاستعلام الثقيل يستهلك مالاً لا وقتاً فقط** |
| **الاستخدام موسمي مركَّز** | ★ **ذروة يومية في ساعات محدودة** |
| **أجهزة ميدانية متفاوتة** | القياس على جهاز متوسط لا جهاز التطوير |
| ★★ **API 24+ كحد أدنى** (`CR-010` ✅ **معتمَد 2026-09-02**) | أجهزة قديمة مدعومة — ⛔⛔★★ **وجهازُ قياس `NFR-PERF-01` مُثَبَّتٌ على Android 8.0** (`IQ-037` الخيار ب) — ★ **وأجهزةُ 7.x مدعومةٌ وظيفياً** ⛔ **بلا ضمانِ أداء** |

| المعرّف | المتطلب | الهدف | الحالة |

| `NFR-PERF-02` | **زمن حفظ توزيعة واعتمادها** | ⏳ | — |
| `NFR-PERF-03` | **زمن عرض أثقل تقرير** | ⏳ | — |

| `NFR-PERF-05` | **زمن الإقلاع البارد** | ⏳ | — |

> لا بطء.**

> ولو بدا الأداء مقبولاً على بيانات قليلة.

## 4. الاستعلامات الأثقل — انتباه دائم

| الاستعلام | الثقل | التخفيف المعتمد |
|---|---|---|
| ★ **تفكيك سعر الجونية** | **يقرأ عمر الجونية كله** | فهرس `sackId ↑ · stockDate ↓` + تنفيذ بتجميع |
| ★ **المتبقي المتأخر** | **مسح أرصدة كل الأيام السابقة** | **قائمة مبنية مسبقاً** |
| **الضمارات المفتوحة لمقوت** | عبر كل المصادر | فهرس مركّب مخصص |
| **بطاقة ضمار المالك** | تسعة بنود × كل مصدر | ★ **من الملخصات الجاهزة** |
| **تقرير شهري** | فترة كاملة | من الملخصات + ترقيم |
| **سجل التدقيق** | ينمو بلا حد | فهرسة ضيقة + ترقيم |

*التفصيل:* [`../06-database/indexing-strategy.md`](../06-database/indexing-strategy.md) §4.

## 5. تجربة الاستخدام تحت البطء

| الحالة | السلوك الواجب |
|---|---|
| **تحميل يتجاوز لحظة قصيرة** | ★ **مؤشر واضح — لا شاشة بيضاء** |
| **شبكة بطيئة جداً** | **تنبيه ولا تعليق صامت** |
| ★ **انقطاع أثناء الحفظ** | ★ **شريط أحمر + تعطيل الحفظ — ⛔ ولا وهم نجاح** |
| **قائمة طويلة** | **تحميل تدريجي** |
