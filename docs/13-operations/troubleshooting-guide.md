## 1. ⛔⛔★★★ «تعذّر إتمام العملية. أعد المحاولة.» على كل عملية كتابة

★ **العطلُ الأكثر تكراراً في تاريخ المشروع — أربع مرات** (`DEBT-49`).

### العَرَض

★ **كلُّ نداءٍ كاتب** — إنشاء دور · حفظ أسعار اليوم · إنشاء توزيعة ·
إنشاء مصدر — **يردّ:**

```text
❌ تعذّر إتمام العملية. أعد المحاولة.
```

⚠️★★ **وثلاث علاماتٍ فارقة تُميّزه عن أي عطلٍ آخر:**

| # | العلامة | الدلالة |
|:-:|---|---|
| ① | ⛔ **سجلُّ Cloud Run خالٍ تماماً** — ولا طلبٌ واحد | ★ **الطلب لا يُرسَل أصلاً** |
| ② | ★ **القراءة تعمل في كل الشاشات** | ⟵ **فالجلسة والشبكة والقواعد سليمة** |
| ③ | ⛔ **الإخفاق عامٌّ لا خاصٌّ بعملية** | ⟵ **فليس قاعدةَ عملٍ ولا صلاحية** |

### السبب الجذري

⛔⛔ **`QTMS_FUNCTIONS_BASE_URL` لم يُمرَّر إلى البناء.**

عنوانُ خدمة العمليات يُحقَن وقت البناء
([`callable_client.dart:39`](../../lib/core/callable/callable_client.dart)):

```dart
const String functionsBaseUrl = String.fromEnvironment('QTMS_FUNCTIONS_BASE_URL');
```

⟵ **وبناءٌ بدونه يجعل `_baseUrl` فارغاً**، فيرتدّ `CallableClient.call` من
**أول سطرٍ فيه** ⛔ **قبل `http.post`**:

```dart
if (_baseUrl.trim().isEmpty) {
  return const Failure(InfrastructureError('QTMS_FUNCTIONS_BASE_URL غير مضبوط في هذا البناء'));
}
```

### ⚠️⚠️★★★ ولماذا كلّف هذا ثلاث جلسات — الرسالةُ تُضلِّل

★★ **النصُّ التشخيصي الدقيق مكتوبٌ فعلاً في الكود** — ⛔ **ولا يصل المستخدم
أبداً.** ⟵ **لأنه ليس رمزَ كتالوج، فيسقط في الحالة الافتراضية:**

| # | الموضع | القيمة |
|:-:|---|---|
| ١ | `CallableClient.call` | `InfrastructureError('QTMS_FUNCTIONS_BASE_URL غير مضبوط…')` |
| ٢ | [`appErrorMessage`](../../lib/core/messages/error_messages.dart) | `callableErrorMessage(diagnostic)` |
| ٣ | `callableErrorMessage` | لا يطابق رمزاً ⟵ `_ => operationFailed` |
| ٤ | الشاشة | **«❌ تعذّر إتمام العملية. أعد المحاولة.»** |

⛔⛔★★ **و«أعد المحاولة» نصيحةٌ لا يمكن أن تنجح أبداً هنا** — ★ **العطل في
البناء لا في اللحظة.** ⟵ **فيُعيد المستخدم المحاولة ويُعيد، والسببُ ثابت.**
★ **ويدّعي تعليقُ [`callable_client.dart:37`](../../lib/core/callable/callable_client.dart)
أن «بناءً بلا إعداد يفشل ظاهراً لا صامتاً»** — ⛔ **وهو صامتٌ عملياً.**
⟵ **وسُجِّل ديْناً مستقلاً: `DEBT-52`.**

### ✅ العلاج — والأمر الصحيح كاملاً

```bash
flutter run --flavor staging -d emulator-5554 \
  --dart-define-from-file=.secrets/qtms-staging-qa-account.env
```

★★ **و`QTMS_FUNCTIONS_BASE_URL` مُضافٌ إلى ذلك الملف منذ 2026-08-28** —
⟵ **فلا حاجة لتمريره منفصلاً بعد اليوم.**

⛔⛔★★ **لكنِ انتبه — `.secrets/` مُستبعَدٌ من المستودع** (`.gitignore:55`):
⟵ **فعلى أي نسخةٍ جديدة من المشروع يعود الملف بلا هذا المفتاح**، ★ **والعَلَم
يُمرَّر يدوياً حتى يُضاف:**

```bash
  --dart-define=QTMS_FUNCTIONS_BASE_URL=https://qtms-callables-7stgg3ngga-ww.a.run.app
```

⚠️ **والعنوان معرّفٌ لا سرّ** (`environments.md` §1.3) — ★ **ومصادرُه الموثوقة
الثلاثة في المشروع:** [`tool/grant_staging_qa_access.py:21`](../../tool/grant_staging_qa_access.py) ·
[`tool/seed_staging_master_data.py:13`](../../tool/seed_staging_master_data.py) ·
تقرير `run3` §7. ⛔ **ولا يُخمَّن.**

### ★★★ خطوةُ التحقق الإلزامية — ⛔ قبل أي اختبار محاكٍ لمسار كتابة

⛔⛔ **ولا يُكتفى بأن الشاشة قالت «حُفِظ»** — ★ **يُقاس من جهة الخادم:**

```bash
gcloud logging read 'resource.type="cloud_run_revision" AND resource.labels.service_name="qtms-callables" AND timestamp>="<وقتك بصيغة UTC>"' --project qtms-orimind-master --limit 15 --format="value(timestamp,httpRequest.requestMethod,httpRequest.requestUrl,httpRequest.status)"
```

**والمتوقَّع سطرٌ كهذا** (شاهدُ 2026-08-28 الفعلي):

```text
2026-08-28T01:45:17Z  POST  https://qtms-callables-…/createRole  200
```

⛔⛔★★★ **وسجلٌّ خالٍ = العطلُ أعلاه بعينه** — ⛔ **ولا تُفسِّره بغيره**، ولا
تُلاحق القواعد ولا المصادقة ولا IAM: ⟵ **الطلبُ لم يُرسَل.**

★ **وفحصٌ أسرع بلا تطبيق** — **يُثبت أن الخدمة حيّة وتحرس نفسها:**

```bash
curl -s -X POST https://qtms-callables-7stgg3ngga-ww.a.run.app/createRole -H 'content-type: application/json' -d '{"data":{}}'
```

**والمتوقَّع `401` بجسمنا نحن:**
`{"error":{"status":"UNAUTHENTICATED","message":"ERR_AUTH_003",…}}`
⟵ ★ **فإن جاء `401` بنصٍّ ليس نصَّنا فهو العطل §2** ⛔ **لا هذا.**

## 2. ⛔⛔ `401` بنصٍّ ليس نصَّنا — الخدمة نُشرت بـ`--no-allow-unauthenticated`

### السبب

⛔ **الرايةُ تُزيل ربطَ `allUsers` بـ`roles/run.invoker`** — ⟵ **فتحرس IAM
البابَ قبل أن يصل الطلبُ إلى كودنا**، ★ **وطبقةُ IAM لا تفهم رمز Firebase
أصلاً** (`api-overview.md`). ⟵ ⛔ **فيسقط التطبيقُ كلُّه.**

### ✅ العلاج

⛔⛔★★★ **لا تُنشَر هذه الخدمة بـ`--no-allow-unauthenticated` إطلاقاً** —
★ **تحرسُ نفسَها برمز Firebase داخل الكود** (`ERR_AUTH_003`).
⚠️★★ **وإصلاحُ الربط تغييرُ وضعِ أمانٍ لخدمةٍ حيّة** — ⛔ **لا يُنفَّذ ذاتياً**:
★ **يُسلَّم الأمرُ للمالك** (بروتوكول التشغيل §ج).

## 3. ⛔⛔★★★ «يجب إدخال سبب التعديل قبل الحفظ» على حقلٍ معنون «اختياري»

★ **رُصد 2026-08-28 — `DEBT-53`.**

### العَرَض

★ **الحقل معنونٌ «سبب التعديل (اختياري)» حرفياً** — ⛔ **والحفظ يُرفَض
لغيابه** بـ«❌ يجب إدخال سبب التعديل قبل الحفظ.» (`ERR_AMEND_002`).

### السبب — ⛔ وليس عطلاً في التطبيق

⛔⛔ **الخدمةُ المنشورة على التجريبية متأخّرةٌ عن `ADR-0020`.**

★ **الإصدار الحيّ `qtms-callables-00016-65v` نُشر `2026-08-27T05:22:06Z`** —
**و`ADR-0020` اعتُمد بعده في اليوم نفسه** ⟵ **فالصورةُ المنشورة تسبق تعديلَ
`functions/` الذي ألغى إلزامَ السبب.**

⛅ **والقياسُ المميِّز:** **سجلُّ Cloud Run يُظهر الطلبَ واصلاً بـ`400`** —
⟵ ⛔ **فالرافضُ الخادمُ لا العميل** (⚠️ **وسجلٌّ خالٍ يعني العطل §1 لا هذا**).
✅ **والكودُ المحلي يقبلها:** `cd functions && dart test --plain-name "ADR-0020"`.

### ⛔⛔★★★ الأثر الأخطر — يُقلب التحقق ضدّ نفسه

★ **أيُّ اختبارٍ حيٍّ يُجرى على التجريبية الآن يُثبت السلوكَ المُلغى ويُوثَّق
نجاحاً** — ⟵ **فتُغلَق زياداتٌ على شهادةِ بيئةٍ متأخّرة.**
⛔ **فلا يُعتمَد تحقّقٌ حيٌّ لمسار سببٍ قبل إعادة النشر.**

### العلاج

⛔ **إعادةُ نشر `qtms-callables` على التجريبية** — ★ **فعلٌ يُسلَّم للمالك**
(بروتوكول التشغيل §ج) ⛔ **ولا يُنفَّذ ذاتياً**، ★ **ولا يُنشَر بـ
`--no-allow-unauthenticated`** (§2).

★★ **والقاعدة العامة:** **المنشورُ يُقاس بمعرّف إصداره وتاريخِه** — ⛔ **لا
بحالة المستودع**، ★ **و`dart test` أخضرُ لا يقول شيئاً عمّا يعمل في السحابة:**

```bash
gcloud run services describe qtms-callables --project qtms-orimind-master --region me-central1 --format="value(status.latestReadyRevisionName)"
```
