## 1. ⛔⛔★★★ «تعذّر إتمام العملية. أعد المحاولة.» على كل عملية كتابة

★ **العطلُ الأكثر تكراراً في تاريخ المشروع — أربع مرات** (`DEBT-49`).

### العَرَض

★ **كلُّ نداءٍ كاتب** — إنشاء دور · حفظ أسعار اليوم · إنشاء توزيعة ·
إنشاء مصدر — **يردّ:**

```text
❌ تعذّر إتمام العملية. أعد المحاولة.
```

⚠️★★ **وثلاث علاماتٍ فارقة تُميّزه عن أي عطلٍ آخر:**

| # | العلامة | الدلالة |
|:-:|---|---|
| ① | ⛔ **سجلُّ Cloud Run خالٍ تماماً** — ولا طلبٌ واحد | ★ **الطلب لا يُرسَل أصلاً** |
| ② | ★ **القراءة تعمل في كل الشاشات** | ⟵ **فالجلسة والشبكة والقواعد سليمة** |
| ③ | ⛔ **الإخفاق عامٌّ لا خاصٌّ بعملية** | ⟵ **فليس قاعدةَ عملٍ ولا صلاحية** |

### السبب الجذري

⛔⛔ **`QTMS_FUNCTIONS_BASE_URL` لم يُمرَّر إلى البناء.**

عنوانُ خدمة العمليات يُحقَن وقت البناء
([`callable_client.dart:39`](../../lib/core/callable/callable_client.dart)):

```dart
const String functionsBaseUrl = String.fromEnvironment('QTMS_FUNCTIONS_BASE_URL');
```

⟵ **وبناءٌ بدونه يجعل `_baseUrl` فارغاً**، فيرتدّ `CallableClient.call` من
**أول سطرٍ فيه** ⛔ **قبل `http.post`**:

```dart
if (_baseUrl.trim().isEmpty) {
  return const Failure(InfrastructureError('QTMS_FUNCTIONS_BASE_URL غير مضبوط في هذا البناء'));
}
```

### ⚠️⚠️★★★ ولماذا كلّف هذا ثلاث جلسات — الرسالةُ تُضلِّل

★★ **النصُّ التشخيصي الدقيق مكتوبٌ فعلاً في الكود** — ⛔ **ولا يصل المستخدم
أبداً.** ⟵ **لأنه ليس رمزَ كتالوج، فيسقط في الحالة الافتراضية:**

| # | الموضع | القيمة |
|:-:|---|---|
| ١ | `CallableClient.call` | `InfrastructureError('QTMS_FUNCTIONS_BASE_URL غير مضبوط…')` |
| ٢ | [`appErrorMessage`](../../lib/core/messages/error_messages.dart) | `callableErrorMessage(diagnostic)` |
| ٣ | `callableErrorMessage` | لا يطابق رمزاً ⟵ `_ => operationFailed` |
| ٤ | الشاشة | **«❌ تعذّر إتمام العملية. أعد المحاولة.»** |

⛔⛔★★ **و«أعد المحاولة» نصيحةٌ لا يمكن أن تنجح أبداً هنا** — ★ **العطل في
البناء لا في اللحظة.** ⟵ **فيُعيد المستخدم المحاولة ويُعيد، والسببُ ثابت.**
★ **ويدّعي تعليقُ [`callable_client.dart:37`](../../lib/core/callable/callable_client.dart)
أن «بناءً بلا إعداد يفشل ظاهراً لا صامتاً»** — ⛔ **وهو صامتٌ عملياً.**
⟵ **وسُجِّل ديْناً مستقلاً: `DEBT-52`.**

### ✅ العلاج — والأمر الصحيح كاملاً

✅★★★ **و`QTMS_FUNCTIONS_BASE_URL` صار مُضمَّناً في المستودع منذ 2026-08-28**
(`ADR-0022`) — ⟵ **فالأمرُ الكامل يمرِّر ملفّين لا واحداً:**

```bash

```

★ **والأول** [`config/qtms-public-defines.env`](../../config/qtms-public-defines.env)
**مُلتزَمٌ به ويصحب `git clone`** ⟵ ✅ **فلا نسخةَ مشروعٍ تبدأ بلا القيمة بعد
اليوم** — ⛔ **وهو ما تكرّر أربع مرات قبله.** ★ **والثاني `.secrets/` كما هو
مستبعَدٌ**، ⟵ **ويغلب الأولَ عند التصادم لأنه آخِرٌ** (`ADR-0022` القاعدة 4).

⚠️ **والعنوان معرّفٌ لا سرّ** (`environments.md` §1.3) — ★ **ومصدرُه الحاكم
اليوم ملفُّ الثوابت أعلاه**، **وتؤكّده ثلاثةُ مواضع قائمة:**
[`tool/grant_staging_qa_access.py:21`](../../tool/grant_staging_qa_access.py) ·
[`tool/seed_staging_master_data.py:13`](../../tool/seed_staging_master_data.py) ·

### ★★★ خطوةُ التحقق الإلزامية — ⛔ قبل أي اختبار محاكٍ لمسار كتابة

⛔⛔ **ولا يُكتفى بأن الشاشة قالت «حُفِظ»** — ★ **يُقاس من جهة الخادم:**
