## 1. التسمية

```text
RB-<السيناريو>.md
```

## 2. ★ لماذا هذه الملفات موجودة

> **الإجراء المكتوب مسبقاً أدق من الارتجال تحت الضغط** — ★ **وفي نظام مالي،
> الارتجال يُنتج ضرراً لا يُلغى.**

## 4. ★ قالب كل دليل

```markdown
# RB-<الاسم>

## متى يُستخدَم
## ★ ما لا تفعله        ← أولاً دائماً
## الخطوات
## التحقق من النجاح
## متى تُصعّد
```

## 5. ★ قواعد ثابتة في كل دليل

| # | القاعدة |
|---|---|
| 1 | ★ **إن مسّ الأمر بيانات: جمّد الكتابة أولاً** |
| 2 | ⛔ **لا تصحيح يدوي لرصيد** — ★ **إعادة بناء من الدفتر** |
| 3 | ★ **الدفتر مصدر الحقيقة — والملخص مشتقّ** |
| 4 | **كل تدخّل يُسجَّل ويُبلَّغ للمالك إن مسّ أرقاماً** |
