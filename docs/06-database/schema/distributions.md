# مجموعة: `distributions` — التوزيعات (الضمارات)

| البند | القيمة |
|---|---|
| **الغرض** | صرف على الحساب ⟵ **إنشاء/توسيع الضمار** — وحدة المديونية |
| **المفتاح** | ★ **`{dealerId}_{sourceId}_{stockDate}`** |
| **الطبيعة** | مستند تشغيلي · **لا يُحذف** |

> ★ **الضمار ليس مجموعة مستقلة** — هو **هذا المستند نفسه** مضافاً إليه حقول
> التسوية، لأن لكل (مقوت × مصدر × تاريخ مخزون) **توزيعة واحدة فقط**.
> **والمعرّف المركّب هو ما يفرض `GR-18` بنيوياً** — فمحاولة إنشاء ثانٍ
> **تفشل في القاعدة نفسها**، فيُفتَح الموجود للتعديل.

## الحقول الحاكمة
| الحقل | ملاحظة |
|---|---|
| ★ `stockDate` ⚙️ 🔒 | **يوم الضمار** — تاريخ اليوم عادةً · **أو تاريخ اليوم الأصلي في التصريف المتأخر** |
| `entryDate` | **يختلف عن `stockDate` في التصريف المتأخر** |
| `lines[]` | `itemKey` · `itemName` · ★ `sackId?` · ★ `unit` · `quantity` · **`unitPrice?` (مُجمَّد)** · `lineTotal` |
| ★ `debtValue` 🧮 | **مجموع السطور المسعَّرة فقط** |
| `unpricedLineCount` 🧮 | عدّاد ⏳ |
| `totalPieces` · `totalWeight` 🧮 | **منفصلان دائماً — لا يُجمعان** |
| ★ `settledAmount` · `discountedAmount` · `remaining` | ⛅ **تكتبها السحابة — لا التطبيق** |
| ★ `settlementStatus` | مفتوح / مفتوح جزئياً / مغلق |
| `status` | معتمد / **مسعَّر جزئياً** / مسعَّر / ملغى |

## القواعد الحرجة
1. ★ **الخصم المخزني فوري في كل الأحوال** — **والمديونية بقيمة السطور المسعَّرة فقط**.
2. ★ **إخفاء عمود السعر عمّن لا يملك صلاحيته لا يعني أن التوزيعة بلا سعر** — يُطبَّق السعر تلقائياً وتُحتسب قيمة الضمار كاملة (`ت-12`).
3. **قواعد الحماية ترفض أي مستند يحمل سعراً من مُرسِل لا يملك الصلاحية.**
4. **لا يُلغى ضمار سُدِّد كلياً أو جزئياً** حتى تُعالَج المقبوضات والخصومات.
5. **كل سطر من نوع ينتمي لجونية يُطلق إعادة احتساب سعرها** — ⚠️ **بتجميع**.
6. **التوزيع بالكيلوجرام مدعوم بثلاث خانات** — ولا يُجمع مع الحبات.
7. ★★ **قيمة السطر الوزني تُقرَّب لأقرب ريال ثم تُخزَّن `int`** — **الموضع
   الثالث للتقريب** ([`ADR-0019`](../../03-architecture/adr/ADR-0019-weighted-line-total-rounding.md)
   · `IQ-026`). ⛔ **والسطر المعدود لا يمرّ به** · ★ **و`debtValue` مجموعُ
   قيمٍ مقرَّبةٍ أصلاً** ⛔ **فلا تقريب ثانٍ عليها.**

## الفهارس
`sourceId ↑ · stockDate ↓` · ★ **`dealerId ↑ · settlementStatus ↑ · stockDate ↑`** · `sourceId ↑ · status ↑ · stockDate ↓`
