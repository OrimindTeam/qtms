| البند | القيمة |
|---|---|
| **الغرض** | ★ **مصدر الحقيقة الوحيد لرصيد كل مقوت في كل مصدر** — `GR-02` |
| **الطبيعة** | **دفتر · لا يُحذف منه شيء · ويُعدَّل بضوابط** |

## الحقول
| الحقل | ملاحظة |
|---|---|
| `dealerId` · `dealerName` | **الاسم مكرَّر عمداً** فلا يتغيّر تاريخياً |
| ★ `sourceId` | **إلزامي — الحساب مرتبط بالمصدر** |
| `debtLotId?` | الضمار المتأثر |
| `direction` | **مدين (عليه)** / **دائن (له)** |

| ★ `entryType` | ضمار · قبض · خصم · **تطبيق فائض** |
| `sourceDocType` · `sourceDocId` · `sourceDocNumber` | — |
| `entryDate` · `memo` | **البيان قد يُكتب آلياً** عند تطبيق الفائض |
| ★ `isCancelled` · بيانات التعديل | — |

## المعادلات
```text
إجمالي المدين = Σ(قيم الضمارات)
إجمالي الدائن = Σ(المقبوضات) + Σ(الخصومات) + Σ(الفائض المُطبَّق)
الرصيد        = المدين − الدائن          [غير الملغاة فقط]

الرصيد > 0 ⟸ عليه للمحل   ·   = 0 ⟸ مسدَّد   ·   < 0 ⟸ له فائض
```

## القواعد الحرجة
1. ★ **لا تُجمع أرصدة المقوت بين المصادر في أي عملية مالية** — الجمع **للعرض فقط**.
2. ★ **البيع النقدي والسحبيات والخرجيات لا تكتب هنا إطلاقاً** (`GR-33` · `GR-44`).
3. **حركة دائنة لكل سطر قبض أو خصم** — لا حركة مجمّعة.
4. **كشف الحساب يُبنى من هذا الدفتر حصراً لا من أرقام مخزَّنة.**
5. **الحركات الملغاة تُستبعَد من الأرصدة** — ويجوز إظهارها مشطوبة بخيار.
