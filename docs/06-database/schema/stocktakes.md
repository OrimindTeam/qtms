# مجموعة: `stocktakes` — الجرد والتسويات

| البند | القيمة |
|---|---|
| **الغرض** | **القناة المشروعة الوحيدة** لمعالجة فرق مخزني **غير مفسَّر بمستند** |
| **المفتاح** | `documentNumber` (`STK-YYYYMMDD-###`) |
| **الطبيعة** | مستند تشغيلي · **لا يُحذف** |

## الحقول
| الحقل | ملاحظة |
|---|---|
| ★ `stockDate` | **اليوم المجرود** — اليوم الجاري افتراضياً · **وجرد يوم سابق بصلاحية** |
| ★ `sourceId` | **مصدر واحد ويوم واحد لكل مستند جرد** |
| `bookBalance` 🧮 🔒 | ★ **يُجمَّد لحظة بدء الجرد** |
| ★ `actualCount` | **بالحبة أو بالكيلوجرام حسب وحدة كل نوع** |
| `difference` 🧮 | = الفعلي − الدفتري |
| ★ `differenceReason` | **نصي إلزامي لكل فرق ≠ 0** |

## القواعد
1. ★ **حركات التسوية تُوسَم `movementTag = adjustment`** وتُستثنى من **تقارير المبيعات** ومن **احتساب سعر الجونية** ومن **استحقاق الرعوي** (`BR-M16-03`).
2. **لا جردان متزامنان** على نفس المصدر ونفس اليوم.
3. **جرد يوم سابق يُعيد بناء ملخصات ذلك اليوم بأثر رجعي** (`BR-M16-07`).
4. **النقص المفسَّر له قنواته الأخرى:** التوزيع · البيع · السحبيات والخرجيات · **الإتلاف** — والجرد **للنقص غير المفسَّر وحده**.
5. **قيد كامل في سجل التدقيق** عند الاعتماد.
