# مجموعة: `stocktakes` — الجرد والتسويات

| البند | القيمة |
|---|---|
| **الغرض** | **القناة المشروعة الوحيدة** لمعالجة فرق مخزني **غير مفسَّر بمستند** |
| **المفتاح** | `documentNumber` (`STK-YYYYMMDD-###`) |
| **الطبيعة** | مستند تشغيلي · **لا يُحذف** |

## الحقول
| الحقل | ملاحظة |
|---|---|
| ★ `stockDate` | **اليوم المجرود** — اليوم الجاري افتراضياً · **وجرد يوم سابق بصلاحية `stocktakePriorDay`** |
| ★ `sourceId` · `sourceName` | **مصدر واحد ويوم واحد لكل مستند جرد** |
| ★★ `status` | ✅ **`draft` / `approved` / `cancelled`** — ★ **المرحلةُ حقلٌ صريح** ⛔ **لا تُستنتَج من امتلاء الحقول** |
| `lines[]` · `lineCount` | **سطرٌ لكل نوع مجرود** — ★ **بمفتاحٍ مركّب `itemKey`** ⛔ **لا `itemName` المجرَّد** ([`DEBT-86`]) |
| `lines[].bookBalance` 🧮 🔒 | ★★★ **يُجمَّد لحظة بدء الجرد** — ⛔⛔ **ولا يعبر الحمولةَ صعوداً أبداً**: ★ **تكتبه السحابةُ من الدفتر وتقرؤه منه عند الاعتماد** |
| ★ `lines[].actualCount` | **بالحبة أو بالكيلوجرام حسب وحدة كل نوع** — ⛔ **ووحدةٌ مخالفة رفضٌ صريح** (`GR-19`) · ★ **والصفرُ عدٌّ مشروع** («لم يبقَ شيء» معلومةٌ لا غياب) |
| `lines[].difference` 🧮 | = الفعلي − الدفتري **بإشارته** — ⛔ **ولا قيمةَ مطلقة تُخفي اتجاهه** |
| ★ `lines[].differenceReason` | ★★ **نصيٌّ اختياري** ([`ADR-0020`]) — ⚠️ **وكان إلزامياً لكل فرق ≠ 0 حتى 2026-08-27** |
| `reason`؟ · `amendReason`؟ · `cancelReason`؟ | ★ **كلُّها اختيارية** ([`ADR-0020`]) — ⛔ **ولا يُعبَّئها التطبيق نيابةً عن المستخدم**، ★ **والفراغُ غيابٌ لا نصٌّ فارغ** |
| `createdBy` · ★ `approvedBy` · `amendedBy` · `amendCount` · `cancelledBy` | ★ **من نفَّذ كلَّ مرحلة** — ⛔ **ولا يُحذَف مستندٌ ولا سطر** (`GR-07`) |

## القواعد
1. ★ **حركات التسوية تُوسَم `movementTag = adjustment`** وتُستثنى من **تقارير المبيعات** ومن **احتساب سعر الجونية** ومن **استحقاق الرعوي** (`BR-M16-03`). ✅★★ **ومُنفَّذٌ بغيابٍ بنيوي** (`WU-022`): ⛔ **لا `sackId` في حركة التسوية إطلاقاً**، ⛔ **ولا يُطلَق مُحتسِبُ سعر الجونية ولا بانى ملخصات ضمار المالك.**
2. **لا جردان متزامنان** على نفس المصدر ونفس اليوم. ✅★★★ **مُنفَّذٌ باستعلامٍ داخل المعاملة** على (`sourceId` × `stockDate`) — ★ **والمسوّدةُ وحدَها تحجب** (`ERR_STOCK_006`) ⛔ **والمعتمَدُ والملغى لا يقفلان اليوم.**
3. **جرد يوم سابق يُعيد بناء ملخصات ذلك اليوم بأثر رجعي** (`BR-M16-07`). ✅ **و`item_daily_balances` و`aged_remainders` يُعاد بناؤهما داخل المعاملة نفسِها** · ★★ **وملخصاتُ اليوم بـ`rebuildDayRetroactively`** (`WU-021`).
4. **النقص المفسَّر له قنواته الأخرى:** التوزيع · البيع · السحبيات والخرجيات · **الإتلاف** — والجرد **للنقص غير المفسَّر وحده**.
5. **قيد كامل في سجل التدقيق** عند الاعتماد. ✅ **وعند البدء والتعديل والإلغاء كذلك** — ★ **نوعُ الكيان `stocktake`** ⛔ **والقيدُ والمستندُ في معاملةٍ واحدة** ([`ADR-0013`]).
6. ✅★★★ **والفرقُ يُحسَب على الرصيد *المُجمَّد*** ⛔ **لا على رصيدٍ يُعاد قراءتُه عند الاعتماد** — ★ **فحركةٌ وقعت أثناء العدّ تبقى محسوبة**: ⟵ **وإلا فقد التجميدُ معناه كلَّه** (`FR-M16-03` · `FR-M16-09`).
7. ✅★★ **والفرقُ الصفري بلا حركةٍ أصلاً** — ⛔ **لا حركةٌ صفرية في الدفتر**: ★ **وفي التعديل تُوسَم الحركةُ الملغاة `isCancelled`** (`GR-07`) ⛔ **ولا تُحذَف.**
