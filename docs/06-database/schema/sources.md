# مجموعة: `sources` — المصادر

| البند | القيمة |
|---|---|
| **الغرض** | تعريف المصادر — **وحدة الفصل الكبرى في النظام** |
| **المفتاح** | `sourceId` (`SRC-001`) |
| **الطبيعة** | LIVING · **لا تُحذف أبداً** |

## الحقول الحاكمة
| الحقل | ملاحظة |
|---|---|
| `normalizedName` | **أساس فحص التفرد** — عبر `unique_source_names` |
| ★ `requiresSupplierOnIntake` | يتحكم بظهور حقل الرعوي في `M6`/`M7` — **وتغييره لا يمسّ المستندات السابقة** |
| `isActive` | **التعطيل بديل الحذف** |

## القواعد
1. **الحذف مرفوض دائماً** في قواعد الحماية — التعطيل فقط (`BR-M2-01`).
2. **إضافة مصدر تُشغِّل توليداً تلقائياً في السحابة:** حساب لكل مقوت · حساب لكل رعوي · **نسخة «السكرب»** (`BR-M2-04`).
3. **لا يُعطَّل مصدر له ضمارات مفتوحة أو مخزون غير مصرَّف** إلا بصلاحية مدير وإقرار نصي (`BR-M2-06`).
4. المصدر المعطَّل **لا يظهر في التوريد والتوزيع والبيع والسحبيات الجديدة**، **ويظهر** في المقبوضات والخصومات والتقارير التاريخية.

## من يكتب
صلاحية «إضافة/تعديل/تعطيل مصدر» · **والحذف مرفوض للجميع**.
