# مجموعة: `receipts` — سندات القبض

| البند | القيمة |
|---|---|
| **الغرض** | تسجيل المقبوض وتوزيعه على الضمارات · **وإدارة الفائض** · **ومتابعة الإيداع البنكي** |
| **المفتاح** | `documentNumber` (`RCP-YYYYMMDD-####`) |
| **الطبيعة** | مستند تشغيلي · **لا يُحذف** |

## الحقول الحاكمة
| الحقل | ملاحظة |
|---|---|
| ★ `date` | **يقبل تاريخاً سابقاً بصلاحية · ولا يقبل المستقبلي أبداً** |
| `sourceFilter` | مصدر محدد أو **«الكل»** — يحدد الضمارات المعروضة |
| `totalDebtAtEntry` | **يُحفَظ للعرض التاريخي** |
| `lines[]` | `debtLotId` · `sourceId` · المتبقي قبل · ★ **المبلغ الواصل** · المتبقي بعد · بيان |
| ★ `surplusAmount` · ★ `surplusScope` | **مصدر محدد** أو **«عام»** |
| ★ `isDeposited` 🟡 | **تبدأ «لم يُودع»** |
| ★ `depositNote` · `depositedBy` · `depositedAt` | **الملاحظة إلزامية عند التأكيد** |
| `usedAutoAllocation` | للتدقيق |

## القواعد الحرجة
1. ★ **حركة دائنة لكل سطر** على **الضمار وحساب المقوت في مصدره** — **لا حركة واحدة مجمّعة**.
2. **المبلغ الواصل > 0 ولا يتجاوز المتبقي على ذلك الضمار.**
3. ★ **الفائض يُسدَّد تلقائياً للضمار القادم** ⛅ **ببيان آلي** يذكر تاريخ الدفع.
4. ★ **الفائض بمصدر محدد يخص ضماراته حصراً** · **والعام يُسدَّد لأي مصدر بالأقدم أولاً**.
5. **التوزيع التلقائي يُحسَب محلياً ويُعرَض للمراجعة قبل الحفظ — ولا يكتب شيئاً.**
6. ★ **حقول الإيداع بمسار كتابة منفصل** يشترط صلاحيته **وملاحظة غير فارغة** · **ورؤية الحالة تتطلب صلاحية عرض مستقلة**.
7. ★ **«المقبوض في تاريخ» ≠ «الواصل»** — راجع [`daily-summaries.md`](daily-summaries.md).
8. **كل سند داخل معاملة ذرّية واحدة** — كل السطور أو لا شيء.

## الفهارس
`dealerId ↑ · date ↓` · ★ **`date ↑ · isDeposited ↑`** · `sourceId ↑ · date ↓`
