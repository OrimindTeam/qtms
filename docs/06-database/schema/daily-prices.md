# مجموعة: `daily_prices` — أسعار اليوم

| البند | القيمة |
|---|---|
| **الغرض** | سعرا كل نوع لكل يوم: **سعر التوزيع** و**الحد الأدنى للبيع النقدي** |
| **المفتاح** | ★ **`{sourceId}_{itemKey}_{date}`** |
| **الطبيعة** | LIVING · **يُصفَّر يومياً** |

## الحقول
| الحقل | ملاحظة |
|---|---|
| `itemName` · ★ `unit` | **سعر حبة أو سعر كيلو حسب وحدة النوع** |
| `distributionPrice` | number \| null — **اقتراح لا التزام** |
| `minCashPrice` | number \| null — **مُلزِم فعلاً في البيع النقدي** |
| `isPricingComplete` 🧮 | **السعران معاً موجودان** |
| `lastModifiedAt` · `modifiedBy` | — |

## القواعد الحرجة
1. ★ **التصفير اليومي:** السعر يخص **(المصدر × النوع × اليوم)** — **ولا يُرحَّل تلقائياً إلى الغد** (`GR-31`).
2. ★ **مصدر السعر واحد لا يتكرر:** ما يُدخَل في شاشة التسعير وما يُدخَل في سطر الجونية **يكتبان نفس الحقل** — فتغييره من أي مكان يظهر في الآخر فوراً (`BR-M9-03`).
3. **لا يُطالَب بتسعير نوع لا كمية له في مخزون اليوم** — ولا يظهر أصلاً.
4. ★ **تجميد السعر:** السعر المستخدم **يُنسَخ داخل سطر المستند** لحظة الاعتماد، **فلا يتأثر بأي تسعير لاحق** (`GR-32`).
5. **تعديل سعر بعد استخدامه لا يمسّ أي عملية سابقة إطلاقاً** ويُسجَّل بالقيمة قبل وبعد.
6. **زر «نسخ أسعار أمس» نسخ صريح بإرادة المستخدم** لا ترحيل تلقائي صامت.
7. **متبقي الأيام السابقة لا يظهر هنا** — سعره يُدخَل لحظة تصريفه.

## الفهرس
`sourceId ↑ · date ↑ · isPricingComplete ↑` — لفلتر «تم/لم يتم التسعير».
