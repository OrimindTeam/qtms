# مجموعة: `incoming_count` — الوارد عدداً

| البند | القيمة |
|---|---|
| **الغرض** | توريد بالعدد مباشرة — **بلا أوزان ولا ضريبة ولا حساب رعوي** |
| **المفتاح** | `documentNumber` (`INC-YYYYMMDD-####`) |
| **الطبيعة** | مستند تشغيلي · **لا يُحذف** |

## الحقول الحاكمة
| الحقل | ملاحظة |
|---|---|
| ★ `stockDate` ⚙️ 🔒 | **تاريخ اليوم من الخادم — غير قابل للتغيير إطلاقاً** |
| `entryDate` | للتدقيق |
| `supplierId?` | **يُخزَّن فقط إن كان المصدر يشترطه** — وإلا **لا يُعرَض ولا يُخزَّن** |
| `lines[]` | `itemId` · `itemName` · ★ `unit` · `quantity` (**عدد صحيح > 0**) |

## القواعد
1. ★ **يدخل المخزون بالاسم المجرَّد لا المركّب** — **فلا يدخل احتساب أي جونية** (`BR-M6-10`).
2. **العدد عدد صحيح موجب فقط** — الكسور مرفوضة.
3. **لا سطران لنفس النوع** — يُدمجان تلقائياً مع تنبيه.
4. **قائمة الأنواع مفلترة بالمصدر حصراً** + خيار «أخرى».
5. **لا وزن ولا ضريبة ولا سعر في هذه الوحدة إطلاقاً.**
6. **التعديل مباشر على الحركة** بصلاحية وسبب · **والإلغاء بالوسم** · **والحذف مرفوض**.
7. **لا تنبيه انحراف كمية** *(محذوف بقرار المالك)*.
