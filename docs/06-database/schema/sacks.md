# مجموعة: `sacks` — الجواني

| البند | القيمة |
|---|---|
| **الغرض** | **أعقد مستند في النظام** — منه تُشتق حسابات الرعوي والضريبة وسعر الجونية |
| **المفتاح** | `documentNumber` (`SCK-YYYYMMDD-####`) |
| **الطبيعة** | مستند تشغيلي · **لا يُحذف** |

## الحقول الحاكمة
| الحقل | ملاحظة |
|---|---|
| ★ `stockDate` ⚙️ 🔒 | تاريخ اليوم من الخادم |
| ★ `dailySequence` ⚙️ 🔒 | ⛅ **من السحابة · مستقل لكل مصدر · يبدأ من ١ كل يوم · لا يُعاد استخدامه ولا يتغيّر أبداً** |
| `displayName` | `{الرعوي} - جونية رقم N` — **تعديله بصلاحية · ولا يمسّ الرقم المتسلسل** |
| `totalWeight` · `iceWeight` · ★ `scrapWeight` | decimal(3) — **الكلي > الثلج + السكرب دائماً** |
| ★ `taxPerKilo` | 🔵 **قد تكون معلّقة** |
| `claimableWeight` 🧮 | = الكلي − الثلج − السكرب |
| `lostWeight` · ★ `lostWeightConfirmed` | 🟡 **لا يُسجَّل إلا بزر التأكيد الصريح** |
| `sackTax` 🧮 | = **round**(ضريبة الكيلو × **الوزن الكلي**) (لا المطالب به) — ★ **عدد صحيح بالريال بعد التقريب لأقرب ريال** (`ADR-0015`) |
| ★ `sackRevenue` 🧮 ⛅ | **الإيراد الفعلي المتحقق** — راجع [`supplier-ledger.md`](supplier-ledger.md) |
| ★ `supplierNet` 🧮 | = السعر − الضريبة |
| `isPricingComplete` | مصدر وسم **«⏳ سعر غير نهائي»** |

## سطر الجونية
| الحقل | ملاحظة |
|---|---|
| ★ `compositeName` | **`{النوع} - {الرعوي} - جونية رقم N`** — أساس ربط كل حبة بجونيتها |
| `nature` · ★ `unit` | **مُثبَّتان لحظة الإدخال** |
| `pieceWeightGrams` · ★ `pieceWeightOrigin` | **تهيئة / يدوي / مستنتج** — للتوثيق والتدقيق |
| `lineTotalWeight` | **مُدخَل للعددي · محسوب للوزني** |
| `distributionPrice` · `minCashPrice` | 🔵 **قد يكونان معلّقين** |

> ⚙️ **سطر السكرب يُولَّد تلقائياً** من `scrapWeight` **باسم مركّب ووحدة
> كيلوجرام**، **ويدخل المخزن فور حفظ الرأس — قبل أي نوع آخر**.

## القواعد الحرجة
1. **جدول وزن الحبة بحالاته الثلاث يُنفَّذ حرفياً** — **ولا يُستنتج وزن حبة نوع وزني من الوزن الكلي في أي حال**.
2. **مسارات كتابة منفصلة لكل مجموعة حقول**، ولكل مسار صلاحيته المطابقة.
3. **الوزن الضائع لا يدخل المخزون ولا يُقيَّد له أي قيمة ولا يستحق الرعوي عنه شيئاً.**
4. **التعديل مباشر** بصلاحية وسبب · وتُعاد الأرصدة **وسعر الجونية وصافي الرعوي** احتساباً.

## الفهارس
`sourceId ↑ · stockDate ↓` · **`supplierId ↑ · sourceId ↑ · stockDate ↓`**

## ✅★★ حالة التنفيذ — `WU-004` (2026-08-26)

| الحقل | الحالة |
|---|---|
| `stockDate` · `dailySequence` · `displayName` · الأوزان الثلاثة | ✅ **يكتبها `createSack`** |
| `claimableWeight` · `remainingWeight` · `lostWeight` · `lostWeightConfirmed` | ✅ **مشتقّةٌ من `explainSackWeight`** — ⛔ **ولا تُحسب في موضعٍ ثانٍ** |
| ★ `scrapItemKey` | ✅ **مفتاح سطر السكرب المركّب** — و`null` **إن كان وزنه صفراً** (`ADR-0008` القاعدة 5) |
| السطور بحقولها (`compositeName` مشتقٌّ · `pieceWeightOrigin` مخزَّن) | ✅ **يكتبها `enterSackLines`** |
| `taxPerKilo` · `sackTax` | ✅ **في `finance/current` وحدها** (`ADR-0011`) — **يكتبهما `enterSackTax`** |
| ★ `sackRevenue` · `supplierNet` | ⛔ **لا كاتبَ لهما بعد** — **`M14`** (`WU-015` — المرحلة الثانية) |
| `isPricingComplete` | ✅ **يُحدَّث مع السطور** — ★ **ومصدرُ وسم «⏳ سعر غير نهائي»** |

> ⛔★★ **ولا حقل مالي في الأب إطلاقاً** — ★ **ويحرسه اختبارٌ صريح** في
> `functions/test/sack_intake_test.dart` يفحص غياب الأربعة بالاسم.
