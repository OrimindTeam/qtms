# دفتر: `inventory_ledger` — حركات المخزون

| البند | القيمة |
|---|---|
| **الغرض** | ★ **مصدر الحقيقة الوحيد لكل رصيد مخزني** — `GR-01` |
| **الطبيعة** | **دفتر · لا يُحذف منه شيء أبداً · ويُعدَّل بضوابط** |

> ★ **لا يتغيّر رصيد أي نوع إلا بسطر هنا.**
> **ولا توجد أي واجهة تُعدِّل رقم الرصيد مباشرة** (`BR-M8-03`).

## الحقول
| الحقل | ملاحظة |
|---|---|
| ★ `sourceId` | **إلزامي في كل سطر** |
| ★ `stockDate` | **اليوم الذي تنتمي إليه البضاعة** |
| `entryDate` | متى سُجِّلت فعلاً — **يختلف في التصريف المتأخر** |
| `itemKey` · `itemName` | النوع أو **الاسم المركّب** |
| ★ `sackId?` | **أساس احتساب سعر الجونية** — ✅★★ **يكتبه `WU-004`** · ⛔ **وغائبٌ عن حركات الوارد عدداً عمداً** (`BR-M6-10`) |
| ★ `lineTotalWeight?` · `pieceWeightGrams?` | ⚙️ **بيانٌ تفسيري للتدقيق يكتبه `WU-004`** — ⛔ **ولا يدخل أي جمع رصيد** (`GR-19`): ★ **الرصيد بوحدة النوع وحدها** |
| ★ `isScrapLine?` | ⚙️ **يميّز سطر السكرب المولَّد من الرأس** (`FR-M7-09`) |
| ★ `unit` | حبة / كيلوجرام |
| `direction` · `quantity` · `balanceAfter` | دخول / خروج |
| `sourceDocType` · `sourceDocId` · `sourceDocNumber` | توريد · توزيع · بيع · سحبية · خرجية · إتلاف · جرد |
| ★ `movementTag` | عادية / **تسوية جرد** / **إتلاف** |
| ★ `isCancelled` | **بديل الحركة العكسية** |
| `lastAmendedAt` · `amendedBy` · ★ `amendReason` | **لأن الحركة تُعدَّل في مكانها** (`A-14`) |

## مصادر الحركة
| دخول | خروج |
|---|---|
| الوارد عدداً · الوارد جواني **والسكرب** · تسوية جرد بالزيادة | التوزيع · البيع النقدي · **السحبيات والخرجيات (بند قات)** · **الإتلاف** · تسوية جرد بالنقص |

> **لا توجد حركات عكسية ولا تصحيحية ضمن المصادر أعلاه** (`A-14`).

## القواعد الحرجة
1. ★ **الرصيد السالب ممنوع تماماً** — **بطبقتين: المعاملة الذرّية + قواعد الحماية**.
2. **الرصيد يُقرأ داخل المعاملة الذرّية نفسها لا من الملخص.**
3. **الحركة الملغاة لا تدخل أي جمع · والمعدَّلة تدخل بقيمتها الجديدة.**
4. **التعديل يشترط: صلاحية + سبب نصي غير فارغ + قيد إجباري في سجل التدقيق.**
5. **الحذف مرفوض نهائياً لكل المستخدمين بمن فيهم المالك.**

## الفهارس
`sourceId ↑ · itemKey ↑ · stockDate ↓` · `sourceId ↑ · stockDate ↑ · createdAt ↓` · ★ **`sackId ↑ · stockDate ↓`** · `sourceId ↑ · movementTag ↑ · stockDate ↓`

> ⚠️ **لا فهرس على `entryDate`** — للتدقيق فقط، والفهرسة عليه تُغري ببناء
> تقرير خاطئ (`RISK-07`).
