# مجموعة: `items` — أنواع القات

| البند | القيمة |
|---|---|
| **الغرض** | تعريف الأنواع وربطها بمصادرها وتحديد طبيعتها ووحدتها |
| **المفتاح** | `itemId` (`ITM-0001`) |
| **الطبيعة** | LIVING · **لا تُحذف أبداً** |

## الحقول الحاكمة
| الحقل | ملاحظة |
|---|---|
| ★ `sourceIds` | **لا يظهر النوع في مصدر غير مرتبط به إطلاقاً** |
| ★ `normalizedName` | **فريد على مستوى النظام** — يمنع «عود» و«عود  ممتاز» كنوعين |
| ★ `nature` | `countBased` / `weightBased` — **يحدد سلوك حقول الجونية بالكامل** |
| `pieceWeightGrams` | **للوزني فقط · اختياري** — وإن غاب يُدخَل **يدوياً داخل الجونية** |
| ★ `unit` 🔒 | `piece` / `kilogram` — **جزء من هوية النوع ولا يتغيّر بعد أول حركة** |
| ★ `isSystemDefault` | **`true` للسكرب** |

> **لا يحمل النوع أي سعر إطلاقاً** — وقاعدة الحماية **ترفض أي حقل سعر** عليه
> (`BR-M5-06`). الأسعار في `daily_prices` أو داخل سطر الجونية أو التوزيع.

## النوع الافتراضي «السكرب»
| الخاصية | القيمة |
|---|---|
| الإنشاء | ⛅ **من السحابة فقط** — نسخة مستقلة **في كل مصدر** |
| الطبيعة والوحدة | **وزني · كيلوجرام** |
| التعديل/الحذف/التعطيل | ❌ **مرفوض من أي واجهة** |
| المعاملة | **كأي نوع** في المخزون والتسعير والتوزيع والبيع والجرد |

## القواعد
1. **لا يُحذف نوع له أي حركة مخزنية** — التعطيل فقط.
2. **لا توجد عملية دمج نوعين** — العلاج بالتعطيل وإعادة الإدخال الصحيح.
3. **تغيير الوحدة بعد أول حركة مرفوض** — يفسد كل الأرصدة التاريخية.
4. **الإضافة السريعة «أخرى»** من داخل التوريد تربط النوع بالمصدر تلقائياً.
