# دفتر: `outflow_ledger` — السحبيات والخرجيات

| البند | القيمة |
|---|---|
| **الغرض** | ★ **الدفتر الرابع** — لا يخرج قات ولا مال خارج دورة البيع إلا بسطر هنا (`GR-04`) |
| **الطبيعة** | **دفتر · لا يُحذف منه شيء** |

## الحقول
| الحقل | ملاحظة |
|---|---|
| ★ `sourceId` | **إلزامي في كل سطر — حتى لسحبيات المالك** |
| ★ `ledgerType` | **سحبية / خرجية** — **أساس فصل الإجماليات والتقارير والصلاحيات** |
| `category` · `itemType` | قات / مبلغ / أخرى |
| `itemKey` · `sackId?` · `unit` · `quantity` | **لبنود القات فقط** |
| `amount` / `lineValue` | — |
| ★ `documentDate` | **تاريخ الأثر المالي** |
| ★ `stockDate` | **تاريخ الأثر المخزني — لبنود القات · وقد يختلف عن تاريخ السند** |
| `sourceDocType` · `sourceDocId` · `sourceDocNumber` | — |
| `isCancelled` · بيانات التعديل | — |

## القواعد الحرجة
1. ★ **لا يُكتب أي سطر في `dealer_ledger` إطلاقاً** — لا مدين ولا دائن ولا ضمار (`GR-44`).
2. ★ **المصدر إلزامي دائماً** — ولا تُحفَظ سحبية ولا خرجية بلا مصدر (`GR-42`).
3. ★ **السجلّان منفصلان تماماً**: إجماليات وتقارير **وصلاحيات عرض وإنشاء منفصلة** (`GR-43`).
4. ★ **بند «قات» يخرج من المخزون ويستحق الرعوي ثمنه** — قيمته **تدخل سعر الجونية** (`GR-29` · `GR-45`).
5. ★ **تمييز تاريخي إلزامي:** الأثر المالي في **تاريخ السند** · والأثر المخزني في **تاريخ مخزون البضاعة** (`GR-49`).
6. **بندان مستقلان يُطرحان في نهاية بطاقة ضمار المالك** (`GR-46`).
7. **تُطرح من «المقبوض في التاريخ» لا من «الواصل»** في شاشة حركة النقد (`GR-47`).
