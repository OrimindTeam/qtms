# مقترحات التصميم (RFC) — QTMS

| البند | القيمة |
|---|---|
| **الحالة** | ⏳ **لا مقترحات** |

---

## 1. ★ متى يُكتَب RFC

| المحفّز |
|---|
| ★ **اقتراح يمسّ معادلة أو قاعدة عمل مالية** |
| ★ **تغيير في نموذج التفويض** |
| **إضافة وحدة كبيرة غير موصوفة في المصدر** |
| **بديل تقني جوهري** |

> **القالب:** [`../../00-governance/templates/rfc.md`](../../00-governance/templates/rfc.md).

## 2. الفرق عن `ADR`

| RFC | ADR |
|---|---|
| ★ **مقترح للنقاش قبل القرار** | ★ **قرار متَّخَذ بعد النقاش** |
| قابل للرفض | ★ **لا يُعدَّل بعد اعتماده** |
| يعرض بدائل مفتوحة | يذكر البديل المرفوض وسبب رفضه |

## 3. ★ قواعد

| # | القاعدة |
|---|---|
| 1 | ★ **يُنشأ بحالة «مقترح»** — ⛔ **ولا يُعتمَد ذاتياً** |
| 2 | ★ **ما يمسّ قاعدة مالية يحتاج موافقة المالك صراحةً** |
| 3 | ★ **المقبول يُنتج `ADR`** ويُشار إليه منه |
| 4 | **المرفوض يبقى** — ★ **يمنع إعادة طرح الفكرة نفسها لاحقاً** |
