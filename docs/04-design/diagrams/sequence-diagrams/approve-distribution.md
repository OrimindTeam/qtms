# تسلسل: اعتماد توزيع

**المصدر:** `§10.2` · **المتطلب:** `FR-M10-*` · **الوحدة:** `M10`

```mermaid
sequenceDiagram
    autonumber
    actor U as موظف التوزيع
    participant APP as التطبيق
    participant FN as العمليات السحابية
    participant RULES as قواعد الحماية
    participant DB as قاعدة البيانات

    U->>APP: اختيار المصدر والمقوت
    APP->>DB: قراءة توزيعة (مقوت × مصدر × تاريخ مخزون)
    alt توجد توزيعة
        DB-->>APP: المستند الموجود
        APP-->>U: ⚠️ «سيُفتح للتعديل بدل إنشاء توزيع ثانٍ»
    else لا توجد
        APP->>FN: طلب رقم مستند
        FN-->>APP: DST-YYYYMMDD-####
    end

    U->>APP: إدخال السطور (نوع · كمية)
    APP->>APP: تطبيق سعر التسعير اليومي تلقائياً<br/>(ولو كان العمود مخفياً عن المستخدم)
    U->>APP: [ حفظ واعتماد ]

    rect rgb(240,246,255)
        Note over APP,DB: معاملة ذرّية واحدة
        APP->>DB: قراءة رصيد كل نوع في (المصدر × تاريخ المخزون)
        APP->>DB: قراءة الفائض المتاح للمقوت في هذا المصدر
        APP->>APP: تحقق: كل كمية ≤ المتاح
        APP->>RULES: كتابة المستند + حركات المخزون + الحساب
        RULES->>RULES: صلاحية · نطاق المصدر · التاريخ<br/>رصيد ≥ 0 · لا سعر بلا صلاحية
        alt رفض
            RULES-->>APP: ❌ رفض
            APP-->>U: رسالة عربية قابلة للتصرف
        else قبول
            RULES->>DB: مستند التوزيع + سطر «خروج» لكل نوع<br/>+ سطر مدين بقيمة المسعَّر + تحديث الأرصدة
        end
    end

    Note over APP,DB: إن عدّل مستخدم آخر رصيداً مقروءاً قبل الالتزام<br/>تُلغى المعاملة وتُعاد تلقائياً على البيانات الجديدة

    DB-->>FN: مشغّلات بعد النجاح
    par عمليات سحابية متوازية
        FN->>DB: سجل التدقيق (بتاريخي المخزون والإدخال)
        FN->>DB: تطبيق الفائض تلقائياً + بيان آلي
        FN->>DB: تحديث ملخص ضمار المالك لتاريخ المخزون
        FN->>DB: بنود المركز المعلّق للسطور غير المسعَّرة
        FN->>DB: إعادة احتساب سعر الجونية وصافي الرعوي
        FN->>DB: تحديث قائمة المتبقي المتأخر
    end

    APP-->>U: ✅ الضمار أُنشئ · وخيارا واتساب/SMS
```

**نقاط حاكمة:**
1. **الخصم المخزني فوري في كل الأحوال**، **والمديونية بقيمة المسعَّر فقط**.
2. **السعر يُطبَّق تلقائياً ويُحتسب الضمار كاملاً ولو أُخفي العمود** (`ت-12`).
3. **لا استدعاءات خارجية داخل المعاملة** — لأنها تُعاد تلقائياً.
4. **الاختبار المرجعي:** `AT-20` … `AT-25` · `E-01` · `E-04` · `E-05`.
