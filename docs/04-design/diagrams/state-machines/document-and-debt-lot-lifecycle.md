# آلات الحالة: المستند والضمار

**المصدر:** `§4.2` · `§8.3` · **المتطلب:** `SRS §3.3` · `FR-M10-*`

---

## 1. دورة حياة المستند

```mermaid
stateDiagram-v2
    [*] --> مسودة
    مسودة --> معتمد: اجتياز كل التحققات<br/>داخل معاملة ذرّية
    مسودة --> [*]: حذف فعلي مسموح<br/>(لم يؤثر بعد)

    معتمد --> مسعَّر_جزئياً: تسعير بعض السطور
    مسعَّر_جزئياً --> مسعَّر: تسعير الباقي
    معتمد --> مسعَّر: كل السطور مسعَّرة

    معتمد --> ملغى: صلاحية إلغاء + سبب اختياري (ADR-0020)
    مسعَّر_جزئياً --> ملغى
    مسعَّر --> ملغى
    ملغى --> [*]

    note right of معتمد
      التعديل لا يغيّر الحالة
      يُعدِّل القيم في مكانها
      ويُعيد احتساب الأرصدة
    end note

    note right of ملغى
      يُستبعَد من كل الأرصدة والتقارير
      ❌ بلا أي حركة عكسية
      ❌ ولا يُحذف أبداً
    end note
```

| الحالة | الأثر على المخزون | الأثر على الحساب | قابل للتعديل | قابل للحذف |
|---|---|---|---|---|
| **مسودة** | لا يوجد | لا يوجد | ✅ | ✅ **(الوحيدة)** |
| **معتمد** | ✅ فوري | حسب نوع المستند | ✅ **بصلاحية + سبب + تسجيل** | ❌ |
| **مسعَّر جزئياً** | تم مسبقاً | ✅ **بالمُسعَّر فقط** | ✅ بصلاحية + سبب | ❌ |
| **مسعَّر** | تم مسبقاً | ✅ بالكامل | ✅ بصلاحية + سبب | ❌ |
| **ملغى** | **يُستبعَد** | **يُستبعَد** | ❌ | ❌ |

**قواعد الانتقال الملزمة:**
1. **لا انتقال يعيد مستنداً معتمداً إلى مسودة.**
2. **لا حذف نهائي لأي مستند معتمد** لأي مستخدم **بمن فيهم المالك**.
3. **التعديل لا يغيّر الحالة** — يُعدِّل القيم ويُعيد الاحتساب (`A-14`).
4. **الإلغاء يَسِم المستند وحركاته معاً**، ويشترط **سبباً نصياً**.

> **«مسعَّر جزئياً»:** التوزيعة الواحدة قد تحتوي سطوراً مسعَّرة وأخرى غير
> مسعَّرة معاً. **المديونية تنشأ بقيمة السطور المسعَّرة فقط**، وتبقى الباقية
> في **مركز الإدخالات المعلّقة** حتى تُسعَّر، **وعندها تُضاف قيمتها للضمار**.

## 2. دورة حياة الضمار

```mermaid
stateDiagram-v2
    [*] --> مفتوح: إنشاء التوزيعة
    مفتوح --> مفتوح_جزئياً: قبض أو خصم جزئي
    مفتوح_جزئياً --> مفتوح_جزئياً: قبض/خصم إضافي
    مفتوح --> مغلق: سداد كامل
    مفتوح_جزئياً --> مغلق: سداد المتبقي
    مغلق --> مفتوح_جزئياً: تعديل يرفع قيمة الضمار
    مفتوح --> مفتوح: توسيع (توزيع إضافي لنفس اليوم)
    مفتوح_جزئياً --> مفتوح_جزئياً: توسيع

    note right of مفتوح
      المعرّف المركّب:
      {dealerId}_{sourceId}_{stockDate}
      ⟵ يفرض «توزيعة واحدة» بنيوياً
    end note

    note right of مغلق
      ❌ لا حد زمني للإقفال (ت-11)
      ❌ ولا يُلغى إن سُدِّد كلياً أو جزئياً
    end note
```

```text
المتبقي على الضمار = قيمة الضمار − المسدَّد − المخصوم

المتبقي = قيمة الضمار      → مفتوح
0 < المتبقي < القيمة       → مفتوح جزئياً
المتبقي = 0                → مغلق
```

**قواعد حاكمة:**
1. **الضمار ليس سجلاً مستقلاً** — هو **مستند التوزيع نفسه** مضافاً إليه حقول
   التسوية، لأن لكل **(مقوت × مصدر × تاريخ مخزون)** توزيعة واحدة فقط.
2. **حقول التسوية تكتبها السحابة لا التطبيق.**
3. **توزيع لاحق من نفس اليوم يُوسِّع الضمار القائم** ولا يُنشئ ثانياً —
   **بما في ذلك تصريف متبقٍّ متأخر يُوسِّع ضمار يومه الأصلي**.
4. **لا يُلغى ضمار سُدِّد كلياً أو جزئياً** حتى تُعالَج المقبوضات والخصومات.
5. **الفائض المتاح يُطبَّق تلقائياً** على أي ضمار جديد ببيان آلي.

## 3. دورة حياة القيمة المعلّقة

```mermaid
stateDiagram-v2
    [*] --> معلّقة: حفظ مستند بقيمة 🔵/🟡 متروكة
    معلّقة --> معلّقة: تحديث المستند بلا إدخال القيمة
    معلّقة --> مُدخَلة: ✅ إدخال القيمة فعلياً
    مُدخَلة --> [*]

    note right of معلّقة
      ⏳ دلالة برتقالية في خمسة مواضع
      ولا تمنع أي عملية
    end note

    note right of مُدخَلة
      يختفي البند من المركز
      وتُطلَق إعادة الاحتساب المرتبطة:
      سعر الجونية · قيمة الضمار · ملخص اليوم
    end note
```

## 4. دورة حياة الجونية (اكتمال الاحتساب)

```mermaid
stateDiagram-v2
    [*] --> أوزان_فقط: حفظ الرأس
    أوزان_فقط --> السكرب_مُورَّد: ⚙️ تلقائي فوري
    السكرب_مُورَّد --> أنواع_مُدخَلة: إدخال السطور
    أنواع_مُدخَلة --> وزن_مُفسَّر: تأكيد الوزن الضائع أو تفسير كامل

    وزن_مُفسَّر --> سعر_غير_نهائي: بدء التصريف مع حركات غير مسعَّرة
    سعر_غير_نهائي --> سعر_نهائي: تسعير كل الحركات
    سعر_نهائي --> سعر_غير_نهائي: حركة جديدة غير مسعَّرة<br/>(أو تصريف متأخر)

    note right of سعر_غير_نهائي
      ⏳ الجونية موسومة «سعر غير نهائي»
      وصافي الرعوي غير نهائي
    end note
```

> **سعر الجونية رقم حيّ** يتغيّر حتى اكتمال تصريف كل أنواعها وتسعيرها —
> **ويعود من «نهائي» إلى «غير نهائي»** إن صُرِّف متبقٍّ منها لاحقاً بلا سعر.
