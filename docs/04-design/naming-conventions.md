## 1. المبدأ الحاكم

> **اسم واحد للمفهوم الواحد عبر النظام كله**: من مصطلح القاموس، إلى اسم
> الكيان في الكود، إلى اسم الحقل في قاعدة البيانات، إلى نص الشاشة.
>
> **والمصطلحات العربية للمجال تُترجَم ترجمة ثابتة واحدة** مسجَّلة أدناه —
> **ولا يُستخدَم لها مرادف في أي مكان**.

## 2. معجم الترجمة الملزم

## 4. اصطلاحات قاعدة البيانات

| العنصر | الاصطلاح | مثال |
|---|---|---|
| المجموعات | **`snake_case` جمعاً** | `inventory_movements` |
| الحقول | `camelCase` | `stockDate` · `sourceId` |
| المراجع | لاحقة `Id` | `dealerId` · `sackId` |
| الأسماء المكرَّرة عمداً | لاحقة `Name` | `dealerName` · `sourceName` |
| الحقول المُطبَّعة | بادئة `normalized` | `normalizedPhone` |
| المفاتيح المركّبة | **مفصولة بـ`_` بترتيب ثابت** | `{sourceId}_{itemId}_{stockDate}` |

### ترتيب المفتاح المركّب ملزم

| السجل | المفتاح |
|---|---|
| رصيد النوع في يوم | `{sourceId}_{itemKey}_{stockDate}` |
| رصيد المقوت | `{dealerId}_{sourceId}` |
| رصيد الرعوي | `{supplierId}_{sourceId}` |
| **الضمار** | `{dealerId}_{sourceId}_{stockDate}` ⟵ **يفرض `GR-18` بنيوياً** |
| سعر اليوم | `{sourceId}_{itemKey}_{date}` |
| ملخص اليوم | `{sourceId}_{date}` · و`all_{date}` للتجميعي |

> **ترتيب الأجزاء ثابت لا يُبدَّل** — لأنه يحدد الفهارس وكفاءة الاستعلام.

## 5. ترقيم المستندات

**الصيغة المعتمدة في المصدر — تُنقَل حرفياً:**

| المستند | البادئة |
|---|---|
| وارد عدداً | `INC-YYYYMMDD-####` |
| جونية | `SCK-YYYYMMDD-####` |
| توزيع | `DST-YYYYMMDD-####` |
| بيع نقدي | `CSH-YYYYMMDD-####` |
| سند قبض | `RCP-YYYYMMDD-####` |
| سند خصم | `DSC-YYYYMMDD-####` |
| **سحبية** | `WDR-YYYYMMDD-####` |
| **خرجية** | `EXP-YYYYMMDD-####` |
| جرد | `STK-YYYYMMDD-###` |

**وأكواد الكيانات:** `SRC-001` · `SUP-0001` · `MQT-0001` · `ITM-0001` ·
`USR-0001`.

> **الترقيم تُولِّده السحابة حصراً** — ولا يُولِّده الجهاز أبداً.
> **والرقم المتسلسل اليومي للجونية مستقل لكل مصدر ويبدأ من ١ كل يوم**، ولا
> يُعاد استخدامه ولا يتغيّر حتى لو غُيِّر الاسم أو أُلغيت الجونية.

## 6. صيغة الاسم المركّب

```text
{اسم النوع} - {اسم الرعوي} - جونية رقم {N}
```
وإن كان المصدر لا يشترط الرعوي: `{اسم النوع} - جونية رقم {N}`.
**والفاصل ` - ` (مسافة، شرطة، مسافة) ثابت** — لأن البحث والعرض يعتمدانه.

## 7. تسمية الاختبارات

```text
test/capabilities/<القدرة>/domain/<الوحدة>_test.dart
```
واسم حالة الاختبار **يحمل رمز القاعدة أو اختبار القبول**:
`'BR-M14-01: سعر الجونية = الإيراد الفعلي لا الافتراضي'` ·
`'AT-52: توزيع متبقي أمس يُحتسب في ضمار أمس'`.

## 8. تسمية مستندات التوثيق

**إنجليزية `kebab-case`** كما يفرض UPDS-00 §3 — **لا تُعرَّب**:
`FR-M22.md` · `UC-004-clear-aged-remainder.md` ·
`ADR-0006-dual-date-model.md` · `TC-M10-003.md`.

## 9. ما يُرفَض

| مرفوض | البديل |
|---|---|
| مرادف لمصطلح في جدول §2 | المصطلح الملزم |
| `date` وحدها في سياق مخزني | **`stockDate`** أو **`entryDate`** صراحةً |
| `amount` بلا وحدة في سياق كمية | نوع يحمل وحدته |
| `qty1` · `temp` · `data2` | اسم يصف المعنى |
| اختصار غير معروف في القاموس | الاسم الكامل |
| اسم إنجليزي مترجَم ترجمة حرة | ما في جدول §2 |
