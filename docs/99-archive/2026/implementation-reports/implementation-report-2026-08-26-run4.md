## 3. ⛔⛔★★★ عطلٌ سابعٌ كشفه التشغيل — `DEBT-37`

⛔⛔ **`pieceWeightOrigin` كان يُكتَب `manual` دائماً** — ★ **وحالةُ «تهيئة»

ويصفها بأنها «تجعل مصدر الرقم قابلاً للتدقيق».**
