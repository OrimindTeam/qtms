# الصور والرسوم — QTMS

| البند | القيمة |
|---|---|
| **الحالة** | ⏳ **فارغ** |

---

## 1. المتوقَّع

| الأصل | الاستخدام |
|---|---|
| **رسوم الحالات الفارغة** | ★ **أيقونة داخل دائرة — لا صورة ثقيلة** |
| **رسوم التعريف الأول** | ثلاث شرائح كحد أقصى |
| **رسم حالة الخطأ** | — |
| **رسم انقطاع الاتصال** | ★ **حالة إلزامية في هذا النظام** |

## 2. ★ قواعد

| # | القاعدة |
|---|---|
| 1 | ★ **بسيطة ومتوافقة مع نظام التصميم** — ⛔ **لا أسلوب دخيل** |
| 2 | ★ **تعمل على أسطح الوضع الفاتح** — `bg` · `surface` · ★ **وسطح البطاقة الرئيسية الداكن** (`AM-003`) |
| 3 | ⛔ **لا صور فوتوغرافية في الواجهة** |
| 4 | ⛔ **لا نص محفور داخل الصورة** — ★ **لا يُترجَم ولا يُكبَّر ولا يقرأه قارئ الشاشة** |
| 5 | ★ **مضغوطة** — كل بايت يُحمَّل على شبكة ميدانية |
| 6 | ⛔ **لا بيانات حقيقية في أي لقطة أو رسم** |
| 7 | **الرخصة موثَّقة** |
