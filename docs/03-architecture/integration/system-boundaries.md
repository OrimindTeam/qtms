# حدود النظام — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | **M** |
| **الطبيعة** | **STATIC** — يتغيّر بتغيّر النطاق فقط |
| **المالك** | المهندس المعماري (ARCH) |

## 1. داخل النطاق (مسؤولية الفريق كاملة)

| المجال | المحتوى |
|---|---|
| **التهيئة** | المستخدمون والأدوار والصلاحيات التفصيلية · المصادر · الرعية · المقاوته · الأنواع · الإعداد التأسيسي |
| **التوريد** | الوارد عدداً · الوارد جواني **والسكرب معها** · إدارة الجواني |
| **المخزون** | المخزون حسب المصدر واليوم · **تصريف متبقي الأيام السابقة** · الإتلاف · الجرد والتسويات |
| **التسعير** | التسعير اليومي بسعرين لكل نوع · **بتصفير يومي** |
| **الصرف** | التوزيع (الضمار) · البيع النقدي المباشر · **السحبيات والخرجيات** |
| **المالية** | المقبوضات والفائض · الخصومات · **الإيداع البنكي** · حساب الرعوي · **ضمار المالك** · **حركة النقد في تاريخ** |
| **الرقابة** | سجل التدقيق · 31 تقريراً · كشف حساب المقوت · **مركز الإدخالات المعلّقة** |
| **الإبلاغ** | **فتح** واتساب/الرسائل بنص جاهز · تصدير PDF · طباعة حرارية |

## 2. خارج النطاق — مؤجَّل بقرار صريح

| البند | الحالة | متى |
|---|---|---|
| **تسديد الرعوي (المورّد)** | **الصافي يُحتسب ويُقيَّد فعلاً اليوم** — والشاشة وحدها مؤجَّلة | المرحلة الرابعة بـ`CR` |
| تعدد الفروع | مؤجَّل | المرحلة الرابعة |
| إشعارات واتساب تلقائية عبر مزوّد رسمي | مؤجَّل — المعتمد **فتح المحادثة يدوياً** | المرحلة الرابعة |
| تطبيق مستقل للمقوت | مؤجَّل | المرحلة الرابعة |
| نسخة ويب مساندة | مؤجَّل | المرحلة الرابعة |
| توسعة فئات السحبيات والخرجيات من التهيئة | مؤجَّل — القائمة الحالية **«الحد الأدنى المعتمد»** | المرحلة الرابعة |
| تحليلات تنبؤية للطلب | مؤجَّل — **البند الوحيد الذي قد يُفعِّل `20-ai-ml/`** | المرحلة الرابعة |

## 3. خارج النطاق — مستبعَد نهائياً بقرار

| المستبعَد | السبب |
|---|---|
| **تكلفة الشراء والربحية** | `A-06` — النظام **لا يسجّل تكلفة شراء إطلاقاً**، فلا تكلفة مباع ولا ربح ولا هامش |
| **المحاسبة بالقيد المزدوج** | خارج النطاق صراحةً — النظام مخزني/ذمم لا محاسبي |
| **الرواتب والضرائب الحكومية** | خارج النطاق |
| **العمل بلا اتصال** | **مستبعَد بقرار معماري مقصود** (`ADR-0003`) |
| **وحدة نسخ احتياطي داخل التطبيق** | مستبعَدة — الاعتماد على موثوقية المنصة المُدارة |
| **بوابات دفع إلكتروني** | لا وجود لها — النقد يُسجَّل يدوياً |
| **تكامل مع أي نظام محاسبي خارجي** | لا وجود له |

## 4. حدود المسؤولية عند التكامل الخارجي

| الطرف | ما نضمنه | ما لا نضمنه | السلوك عند الغياب |
|---|---|---|---|
| **المنصة السحابية** | استخدامها بانضباط · وتنبيهات ميزانية · وفهرسة صحيحة | **توافرها** — التزام مزوّد لا هدف داخلي | تعطيل الحفظ + شريط أحمر |
| **خدمات المنصة على الجهاز** | فحص وجودها | تثبيتها | **رسالة صريحة لا فشل صامت** — والجهاز **غير مدعوم** |
| **واتساب** | **فتح المحادثة بنص جاهز** | **الإرسال** (المستخدم يضغط) · ولا وصول الرسالة · **ولا يُسجَّل أي أثر للإرسال** | «تطبيق واتساب غير مثبَّت — هل تريد SMS؟» |
| **الرسائل النصية** | فتح التطبيق بالنص | الإرسال والتكلفة والوصول | تنبيه إن تجاوز النص رسالة + **خيار نسخة مختصرة** |
| **جهات الاتصال** | طلب الإذن **مرة واحدة مع شرح سببه** · وجلب الاسم والرقم معاً | صحة البيانات في الجهاز | إدخال يدوي بديل — **لا يتعطّل شيء** |
| **الطابعة الحرارية** | توليد إيصال بالمقاس | الاتصال والورق | **تصدير PDF بديلاً دائماً** |

## 5. الحدود الأمنية

```text
┌──────────────────────────────────────────────────────┐
│ منطقة غير موثوقة — جهاز المستخدم                      │
│   التطبيق · إخفاء الأزرار · التحقق الاستباقي           │
│   ⚠️ يمكن تعديله — ولا يُعتمَد عليه أمنياً إطلاقاً       │
└───────────────────────┬──────────────────────────────┘
                        │  ← الحد الأمني الحقيقي
┌───────────────────────▼──────────────────────────────┐
│ منطقة موثوقة — المنصة السحابية                        │
│   فحص العميل → قواعد الحماية → المعاملة الذرّية        │
│   ثم العمليات السحابية (تدقيق · إعادة احتساب)          │
│   ★ كل قرار تفويض يقع هنا وحده ★                      │
└──────────────────────────────────────────────────────┘
```

> **القاعدة:** كل ما فوق الخط **تجربة استخدام**، وكل ما تحته **حماية**.
> وأي قاعدة عمل لم تُترجَم إلى ما تحت الخط **غير مُنفَّذة أمنياً**.

## 6. حدود البيانات

| البيانات | داخل النظام | خارجه |
|---|---|---|
| بيانات المستخدمين والصلاحيات | ✅ | كلمات المرور — **في خدمة المصادقة ولا تُخزَّن إطلاقاً** |
| بيانات المقاوته والرعية | ✅ الاسم والهاتف | لا حسابات وصول لهم إطلاقاً |
| المخزون والحركات والذمم | ✅ **مصدر الحقيقة الوحيد** | — |
| ملفات PDF المُصدَّرة | ✅ في تخزين المنصة | نسخة قد يشاركها المستخدم عبر واتساب |
| **سجل محاولات الإرسال** | ❌ **لا وجود له إطلاقاً** *(محذوف بقرار المالك)* | — |
| **معرّف الجهاز في بطاقة المستخدم** | ❌ **لا وجود له** — التتبّع في سجل التدقيق فقط | — |
