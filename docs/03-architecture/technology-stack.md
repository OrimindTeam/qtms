## 2. الطبقة المعتمدة بقرار بشري ✅

> هذه القرارات **لم يذكرها المستند المصدر**، فاقترحها Claude Code بـADR بحالة
> «مقترح». ★ **واعتُمدت جميعاً بقرار صريح من صاحب المشروع في 2026-08-21** —
> `ADR-0009` و`ADR-0010` صارا **«مقبول»**، ويسري عليهما منع التعديل
> (UPDS-05 §4.1).

| المكوّن | القرار المعتمد | التسبيب الهندسي | ADR |
|---|---|---|---|
| **بنية طبقات التطبيق** ✅ | **أربع طبقات:** عرض / تطبيق / **نطاق نقي** / بنية تحتية — **مقسَّمة على ست قدرات لا على الطبقات** | النظام **كثيف قواعد العمل** (55 قاعدة عامة + مئات قواعد الوحدات)، وعزلها عن حزم المنصة يجعلها **قابلة للاختبار بلا سحابة** — شرط عملي لتغطية ≥80٪ | `ADR-0009` |
| **إدارة الحالة** ✅ | **Riverpod** — حقن اعتمادية صريح بأمان نوعي · **والشاشة لا تحوي منطق أعمال إطلاقاً** | **مزوّد الصلاحيات يُقرأ من كل شاشة تقريباً** بلا تمرير يدوي · وإعادة بناء دقيقة تخدم «فتح شاشة < 2 ثانية» | `ADR-0010` |
| **الملاحة** ✅ | **`go_router`** — توجيه تصريحي بمسارات مُعرَّفة | **عمق ثلاثة مستويات كحد أقصى** — قاعدة من نظام التصميم المعتمد · وهو الموجّه المعتمد من فريق الإطار | `ADR-0009` |
| **النمذجة والتسلسل** ✅ | **`freezed` + `json_serializable`** — توليد كود التحويل من/إلى المستندات | مئات الحقول؛ والخطأ اليدوي في اسم حقل = **خلل مالي صامت** (`ADR-0009` القاعدة 6) | `ADR-0009` |
| ★ **لغة العمليات السحابية** ✅ | ★ **Dart** — **بطبقة النطاق نفسها مشتركة بين التطبيق والسحابة**، منشورة عبر `functions_framework` على Cloud Run + Eventarc | ★ **`coding-standards.md` §2.2 يمنع تكرار أي معادلة «ولا في عملية سحابية»** — ولغة ثانية تعني كتابة كل معادلة مالية **مرتين** | `ADR-0009` ② |
| **الاختبار** ✅ | `flutter_test`/`package:test` + **محاكي المنصة السحابية محلياً** لقواعد الحماية | **قواعد الحماية تُختبَر كما يُختبَر الكود** — وإلا بقيت ادعاءً | `docs/08-testing-and-qa/` |
| **التنسيق والفحص الساكن** ✅ | `dart format` + المحلل الرسمي بإعدادات صارمة (`strict-casts` · `strict-inference` · `strict-raw-types`) · **التحذير خطأ في التكامل المستمر** | معيار صناعي بلا أثر وظيفي | `docs/04-design/coding-standards.md` |

> ⚠️ **شرط تحقق مبكر على لغة العمليات السحابية:** Dart **ليست بيئة تشغيل من
> الدرجة الأولى** في Cloud Functions؛ المسار عبر Cloud Run + Eventarc. لذلك
> **تُنفَّذ عيّنة إثبات في «الخطوة صفر»** قبل بناء الدوال السبع — مسجَّلة
> `DEBT-09`. **والبديل عند الفشل يحتاج ADR جديداً**، لا انتقالاً صامتاً
> (`ADR-0009` ②).

> **استثناء موضَّح — لا يناقض «لغة واحدة»:** اختبارات قواعد الحماية تُكتب
> بأداة الاختبار الرسمية للقواعد على المحاكي (بيئة Node). **هذه أداة اختبار
> لا عملية سحابية، ولا تحوي أي معادلة**، فلا تمسّ قاعدة «لغة واحدة للدوال».

## 6. قاعدة إضافة أي اعتمادية جديدة

قبل إضافة أي حزمة:
1. **هل تحلّ مشكلة فعلية قائمة الآن؟** (لا استباقاً)
2. **هل تمسّ الأرصدة أو الصلاحيات؟** ⟵ إن نعم، **تحتاج ADR**.
3. **فحص أمني ورخصي إلزامي** — `docs/07-development/dependency-management-policy.md`.
4. **هل تزيد حجم الحزمة أو عدد القراءات السحابية؟** ⟵ يُقاس ويُوثَّق.
