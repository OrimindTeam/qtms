## 1. الاتصالات الفعلية

| من | إلى | البروتوكول |
|---|---|---|
| التطبيق | خدمة المصادقة | ★ **HTTPS/TLS** |
| التطبيق | قاعدة البيانات السحابية | ★ **TLS** |
| التطبيق | العمليات السحابية | ★ **HTTPS/TLS** |
| التطبيق | التخزين | ★ **TLS** |
| العمليات السحابية | قاعدة البيانات | داخلي في المنصة |

| القاعدة |
|---|
| ★ **لا اتصال بلا تشفير — بلا استثناء** |
| ★ **لا خدمة خارجية غير معتمدة** |
| **حماية العميل تمنع أي عميل غير التطبيق الرسمي** |

## 2. ★ الاعتماد الكامل على الاتصال

```text
★ لا اتصال ⟵ لا نظام.  وهذا قرار تصميمي لا عيب.
```

| السلوك الواجب | المرجع |
|---|---|
| ★ **شريط أحمر ثابت عند الانقطاع** | `ADR-0003` |
| ★ **تعطيل أزرار الحفظ فعلياً** | — |
| ⛔ **لا حفظ محلي ولا طابور مؤجَّل** | ★ **يمنع وهم النجاح** |
| **رسالة عربية صريحة** | كتالوج الرسائل |

> ★ **الغاية:** أن يعرف المستخدم **يقيناً** أن حركته **لم تُسجَّل** — بدل أن
> يظن أنه وزّع بضاعة لم تُخصم فعلاً.

## 3. الشبكة الميدانية — واقع التشغيل

| العامل | الأثر |
|---|---|
| **شبكات متفاوتة الجودة** | ★ **القياس على شبكة بطيئة لا شبكة مكتب** |
| **انقطاعات متكررة** | **التصميم يفترضها لا يستثنيها** |
| **بيانات محدودة** | ★ **تقليل القراءات يخدم المستخدم والتكلفة معاً** |

## 4. الأمن الشبكي

| البند | القاعدة |
|---|---|
| **التشفير** | ★ **TLS في كل اتصال** |
| **التحقق من العميل** | ★ **App Check — رفض العملاء غير الرسميين** |
| **حدود المعدّل** | [`../05-api/rate-limiting-policy.md`](../05-api/rate-limiting-policy.md) |
| **قيود المصدر (Origin)** | حسب إعداد المنصة |
| ⛔ **شبكات عامة غير موثوقة** | **التشفير يكفي — ولا بيانات مخزَّنة محلياً أصلاً** |

## 5. ما لا يوجد

| البند | لماذا |
|---|---|
| شبكة خاصة افتراضية | لا خوادم |
| موازِن حمل | تديره المنصة |
| جدار ناري نديره | ★ **قواعد الحماية هي الجدار الفعلي** |
| نطاق أو شهادة نديرها | لا واجهة ويب |
