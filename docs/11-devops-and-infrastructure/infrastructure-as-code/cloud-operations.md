## 1. ★ ما يُنفَّذ هنا حصراً

> **ما لا يجوز أن يقوم به الجهاز:**

| العملية | لماذا بعيداً عن الجهاز |
|---|---|
| ★ **كتابة سجل التدقيق** | ★ **حتى لا يتحكم الجهاز فيما يُسجَّل عنه** |
| ★ **منح الصلاحيات وسحبها** | ★ **يمنع رفع الامتياز** |
| ★ **ترقيم المستندات** | يمنع الأرقام المكررة |
| **بناء الملخصات وإعادة بنائها** | تقليل القراءات والاتساق |
| **إعادة احتساب سعر الجونية** | يمسّ مستندات متعددة |
| **رصد المتبقي المتأخر** | قائمة مبنية مسبقاً |
| **تطبيق الفائض على ضمار جديد** | قرار آلي موحَّد |
| **إنشاء وحذف بنود المركز المعلّق** | ⛔ **لا يكتبها التطبيق ولا يحذفها المستخدم** |

*الكتالوج الكامل:* [`../../05-api/api-overview.md`](../../05-api/api-overview.md).

## 2. ★ القواعد الملزمة

| # | القاعدة |
|---|---|
| 1 | ★ **idempotent دائماً** — التكرار لا يُضاعف شيئاً |
| 2 | ★ **إعادة البناء من الدفتر — ⛔ لا التراكم على قيمة سابقة** |
| 3 | ★ **فحص الصلاحية داخل العملية نفسها** — لا اعتماداً على من استدعاها |
| 4 | **الفشل يُسجَّل ولا يُترك صامتاً** |
| 5 | **لا استدعاء خارجي داخل معاملة** |
| 6 | ★ **لا تكتب سرّاً ولا بياناً مالياً في السجلات** |
