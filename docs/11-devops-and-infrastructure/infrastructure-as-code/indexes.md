## 2. ★ قواعد النشر

| # | القاعدة |
|---|---|
| 1 | ★ **تُنشَر أولاً — قبل كل شيء آخر** |
| 2 | ★ **الاستعلام بلا فهرس يفشل أو يتحوّل لمسح كامل مكلف** |
| 3 | ★ **كل استعلام جديد يأتي بفهرسه في نفس الدمج** |
| 4 | **الترتيب في الفهرس هو ترتيب الاستعلام** |
| 5 | ⚠️ **لا فهرس مخزني على `entryDate`** — `RISK-07` |
| 6 | **الفهرس غير المستخدَم يُزال** — كلفة كتابة بلا مقابل |

## 3. ★ ملاحظة النشر

> **بناء الفهرس على بيانات كثيرة يستغرق وقتاً** — ★ **فينشر مبكراً**، ولا
> يُترك للحظة التي يحتاجه فيها المستخدم.
