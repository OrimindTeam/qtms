## 1. ★ الشكل العام — بلا خوادم مُدارة ذاتياً

```text
تطبيق أندرويد  (على أجهزة المستخدمين)
        │  ★ اتصال مباشر — لا خادم وسيط
        ▼
┌─ المشروع السحابي المُدار ──────────────────────┐
│  خدمة المصادقة        ← الهوية والمطالبات       │
│  ★ قواعد الحماية       ← ★ طبقة التفويض الوحيدة  │
│  قاعدة البيانات المستندية                      │
│  العمليات السحابية     ← التدقيق · الملخصات ·   │
│                          الترقيم · الصلاحيات    │
│  التخزين              ← الملفات المُصدَّرة        │
│  حماية العميل         ← رفض العملاء غير الرسميين │
│  تتبّع الأعطال (اختياري)                        │
└────────────────────────────────────────────────┘
```

| الخاصية | القيمة |
|---|---|
| **خوادم نديرها** | ★ **لا شيء** |
| **حاويات** | ★ **لا شيء** — راجع [`containerization-strategy.md`](containerization-strategy.md) |
| **شبكات خاصة** | ★ **لا شيء** — راجع [`networking.md`](networking.md) |
| **قاعدة بيانات علائقية** | ★ **لا شيء** |
| ★ **ما نديره فعلاً** | ★ **قواعد الحماية · الفهارس · العمليات السحابية · الإعدادات** |

## 2. ★ ما نُعامله كبنية تحتية

> **البنية التحتية هنا ليست خوادم بل ملفات في المستودع تُنشَر:**

| المكوّن | الموضع | لماذا هو بنية تحتية |
|---|---|---|
| ★ **قواعد الحماية** | المستودع | ★ **طبقة التفويض كلها** — تغييرها تغيير أمني |
| ★ **ملف الفهارس** | المستودع | ★ **بدونه الاستعلام يفشل أو يُكلّف** |
| **العمليات السحابية** | المستودع | منطق الخادم الفعلي |
| **إعداد المشروع السحابي** | يُوثَّق هنا | لا يُغيَّر يدوياً بلا توثيق |

*التفصيل:* [`infrastructure-as-code/`](infrastructure-as-code/).

## 3. المشاريع السحابية

| البيئة | المعرّف | الحالة |
|---|---|---|
| **تجريبية** | `qtms-orimind-master` | ✅ |
| **إنتاج** | `qtms-orimind-c001` | ✅ |
| ★ **موقع قاعدة البيانات** | ★ **`me-central1` (الدوحة)** | ✅ ★ **نُقل من `me-central2` — `ADR-0014`** |

> ⚠️ ★ **موقع القاعدة اختيار نهائي لا رجعة فيه** — وتغييره لاحقاً يعني
> **حذف القاعدة وإعادة إنشاءها، وهو مستحيل عملياً بعد أول بيانات حيّة**.
> ✅ **وقد حُسم: `me-central1` (الدوحة)** — بعد نقل مقصود من `me-central2`
> **وهي فارغة** (`ADR-0014`)، ⚠️ لأن الأخيرة **لا تحمل العمليات السحابية**.
>
> ★ **أثره العملي:** ★ **كل قراءة تذهب للسحابة فعلاً** (لا تخزين مؤقت محلي) —
> ★ **فزمن الرحلة يُدفَع في كل شاشة**، وقرب الموقع مكسب دائم لا لمرة واحدة.
> *التفصيل:* [`environments.md`](environments.md) §1.1.

## 4. الفصل بين البيئات

| القاعدة |
|---|
| ★ **مشروع سحابي مستقل تماماً لكل بيئة** — لا فصل منطقي داخل مشروع واحد |
| ★ **أسرار مستقلة** — [`secrets-and-config-management.md`](secrets-and-config-management.md) |
| ⛔ **لا ربط بيئة تطوير بالإنتاج إطلاقاً** |
| **التجريبية تُعاد تهيئتها دورياً** |

## 5. الاعتماد الخارجي والمخاطر

| الخطر | التخفيف |
|---|---|
| ★ **الارتباط بمزوّد واحد (Vendor Lock-in)** | ★ **مقبول بقرار معماري موثَّق** — والدفاتر تبقى **قابلة للتصدير وإعادة البناء** |
| **انقطاع خدمة المزوّد** | ★ **النظام يتوقف بالكامل** — لا بديل بالتصميم (لا عمل دون اتصال) |
| **تغيّر التسعير** | مراقبة شهرية — [`../10-performance/capacity-planning.md`](../10-performance/capacity-planning.md) |
| **تغيّر واجهات المنصة** | تحديث مُدار — [`../07-development/dependency-management-policy.md`](../07-development/dependency-management-policy.md) |

> ★ **أقوى تخفيف بنيوي:** **الرصيد مشتقّ من الدفتر** — فما دامت الدفاتر
> قابلة للتصدير، **كل شيء آخر قابل لإعادة البناء** (`ADR-0008`).
