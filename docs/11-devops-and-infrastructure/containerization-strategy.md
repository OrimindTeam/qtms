# استراتيجية الحاويات — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | O |
| **الطبيعة** | STATIC |
| **الحالة** | ⛔ **لا تنطبق — بقرار معماري** |

---

## 1. القرار

> ⛔ **لا حاويات في هذا المشروع — ولا حاجة لها.**

| السبب |
|---|
| ★ **لا خوادم نديرها أصلاً** — المنصة السحابية مُدارة بالكامل |
| ★ **العمليات السحابية تُنشَر كدوال** لا كخدمات طويلة العمر |
| **التطبيق حزمة أندرويد** — لا خدمة شبكية |
| **لا قاعدة بيانات نستضيفها** |

## 2. ماذا يقوم مقامها

| الحاجة التي تخدمها الحاويات عادةً | البديل هنا |
|---|---|
| **بيئة تطوير قابلة لإعادة الإنتاج** | ★ **المحاكي المحلي للمنصة + ملف قفل الاعتماديات** |
| **تطابق بيئة التطوير والإنتاج** | ★ **نفس قواعد الحماية ونفس الفهارس في كل البيئات** |
| **عزل التبعيات** | إدارة إصدارات أدوات المنصة |
| **قابلية النقل** | ★ **غير مطلوبة — الارتباط بالمزوّد قرار مقبول موثَّق** |

## 3. متى يُعاد النظر

| المحفّز |
|---|
| **ظهور حاجة لخدمة خلفية طويلة العمر** (لا توجد اليوم) |
| **الرغبة في الخروج من المنصة المُدارة** |
| **حاجة أدوات بناء لبيئة معقّدة يصعب توحيدها** |

> ★ **أي عودة لهذا القرار تستلزم `ADR` جديداً** — ولا تُغيَّر هذه الصفحة وحدها.
