## 1. ★ طبيعة الصيانة هنا

> **نظام يعمل يومياً بذمم متراكمة** — ★ **فالصيانة ليست «تحسينات دورية» بل
> حفاظ على صحة أرقام تنمو كل يوم.**

| النوع | الغرض | الوزن |
|---|---|---|
| ★ **وقائية** | ★ **منع تباعد الأرقام قبل حدوثه** | 🔴 **الأعلى** |
| **تصحيحية** | معالجة الأخطاء | 🔴 |
| **تكيّفية** | مواكبة تغيّر المنصة وأندرويد | 🟠 |
| **تحسينية** | أداء وتجربة | 🟡 |

## 2. الدورات

| الدورة | النشاط |
|---|---|
| **يومياً** | مراجعة الأخطاء · ★ **فشل العمليات السحابية** · فحص عيّنة أرصدة |
| **أسبوعياً** | مراجعة الأخطاء المفتوحة · اكتمال قيود التدقيق |
| **شهرياً** | ★ **الاستهلاك والتكلفة** · **أثقل الاستعلامات** · تحديث الاعتماديات · النسخ الاحتياطي |
| **ربع سنوي** | ★ **اختبار الاسترجاع** · مراجعة الوصول الإداري · مراجعة الدين التقني |
| **مع كل إصدار** | ★ **مراجعة الصلاحيات مقابل جدول التتبع** · تحديث التوثيق |
| **سنوياً** | ★ **تدوير الأسرار** · مراجعة نموذج التهديد · مراجعة قرارات المعمارية |

## 4. ★ ما ينمو ويحتاج انتباهاً دائماً

| البند | النمو | المتابعة |
|---|---|---|
| ★ **سجل التدقيق** | ★ **الأسرع — ⛔ ولا يُقلَّم** | حجمه شهرياً |
| **الدفاتر** | خطّي مع الأيام | أداء الاستعلامات |
| ★ **المتبقي المتأخر** | ★ **يتراكم إن لم يُصفَّ** | ★ **متابعة تشغيلية لا تقنية** |
| **الملخصات** | مع الأيام والمصادر | زمن البناء |

## 5. ★ ما لا يُصان بالتقليم

| البند | القاعدة |
|---|---|
| ★ **سجل التدقيق** | ⛔ **لا حذف ولا تقليم** — ★ **الأرشفة الباردة تُدرَس ولا تُنفَّذ ارتجالاً** |
| ★ **الدفاتر والمستندات** | ⛔ **احتفاظ دائم** |
| **الملخصات** | **تُعاد بناؤها لا تُحذف** |
