## 1. الافتراضات المعتمدة نهائياً من المالك (`A-01` … `A-15`)

> **حالة هذه الافتراضات: نهائية ومعتمدة.** لا تُناقَش ولا تُعدَّل إلا عبر
> `change-requests/CR-*.md` معتمَد. وهي **أساس كل قرار تصميمي لاحق**.

| # | الافتراض |
|---|---|
| **A-01** | **المخزون والحسابات مستقلة تماماً لكل مصدر.** لا يُخلط رصيد مصدر برصيد آخر، ولا ذمة مقوت في مصدر بذمته في مصدر آخر، **ولا حساب رعوي في مصدر بحسابه في مصدر آخر**. |
| **A-02** | العملة الأساسية **الريال اليمني** بدون كسور عشرية في العرض. |
| **A-03** | **الوارد نوعان لا ثالث لهما:** وارد **عدداً** ووارد **جواني**. **والسكرب الناتج من الجونية يُورَّد للمخزن كنوع افتراضي يُباع بالوزن.** |
| **A-04** | المقوت يستلم البضاعة **بالأمانة (على الحساب)** لا شراءً نقدياً — مع استثناء **البيع النقدي المباشر** الذي لا يخص مقوتاً ولا يُنشئ ديناً. |
| **A-05** | **يجوز تأجيل إدخال قيم معيّنة** (الضريبة · الأنواع · الأسعار · سعر القات المسحوب) **بحسب الصلاحية**، على أن **يلاحقها النظام بتنبيه ودلالة حتى تُدخَل**. |
| **A-06** | **لا تُسجَّل تكلفة شراء ولا ربحية.** صافي الرعوي يُحتسب من **الإيراد الفعلي المتحقق** من جونيته ناقصاً ضريبتها. |
| **A-07** | **الضمار** = إجمالي قيمة ما وُزِّع لمقوت واحد من مصدر واحد **من مخزون يوم واحد**. وهو **وحدة المديونية** التي يقع عليها القبض والخصم. |
| **A-08** | **مخزون كل يوم يبقى منسوباً ليومه ولا يُرحَّل.** والمتبقي منه **يظل قابلاً للتصريف** — توزيعاً أو بيعاً نقدياً أو إتلافاً — **ويُحتسب كل ذلك في يومه الأصلي**. **ويجب أن ينبّه النظام عليه حتى يُصرَّف.** |
| **A-09** | **توزيعة واحدة فقط لكل (مقوت × مصدر × يوم مخزون).** وأي توزيع لاحق **يُوسِّع القائمة** ولا يُنشئ مستنداً ثانياً. |
| **A-10** | **تاريخ التوريد والتوزيع والبيع النقدي = تاريخ اليوم دائماً وغير قابل للتغيير إطلاقاً.** والقبض والخصم والسحبيات والخرجيات **تقبل تاريخاً سابقاً بصلاحية** ولا تقبل مستقبلياً أبداً. وتصريف مخزون يوم سابق **استثناء منظَّم** له شاشته. |
| **A-11** | **حساب مالي منفصل لكل مقوت ولكل رعوي في كل مصدر**، يُنشأ **تلقائياً** عند إضافة المقوت أو الرعوي، وعند إضافة أي مصدر جديد. |
| **A-12** | **الأنواع الواردة في جونية — والسكرب معها — تدخل المخزون باسم مركّب** يربطها بجونيتها ورعويها. |
| **A-13** | **سعر الجونية = الإيراد الفعلي المتحقق منها** (توزيعات · بيع نقدي · **قات مسحوب أو مصروف**) بالأسعار المسجَّلة فعلاً — **لا السعر الافتراضي**. |
| **A-14** | **التعديل مباشر على الحركة نفسها بلا حركات تصحيحية**، مع تسجيل كامل في سجل التدقيق. |
| **A-15** | **كل قات يخرج من المخزن يستحق الرعوي ثمنه** — وُزِّع أو بيع نقداً أو **سُحب أو صُرف**. والاستثناء الوحيد: **الإتلاف الموثَّق** والوزن الضائع. |

## 2. القيود التقنية

| # | القيد | الأثر التصميمي الملزم |
|---|---|---|
| **C-01** | **المنصة: أندرويد فقط** (Android 8.0+) بـ Flutter/Dart | لا نسخة iOS ولا ويب في هذا الإصدار |
| **C-02** | **قاعدة البيانات: Cloud Firestore حصراً** | قاعدة مستندية لا علائقية — **لا جداول SQL ولا مخطط علاقي** |
| **C-03** | **لا خادم مستقل ولا REST API** | التطبيق يتصل مباشرةً بالمنصة؛ ما لا يجوز للجهاز فعله يُنفَّذ بعملية سحابية |
| **C-04** | **خدمات Google Play شرط تشغيلي إلزامي** | الأجهزة بدونها **غير مدعومة** — ويجب **رسالة واضحة عند غيابها لا فشل صامت** |
| **C-05** | **الاتصال بالإنترنت إلزامي** — لا وضع بلا اتصال ولا طابور محلي ولا مزامنة لاحقة | **تعطيل التخزين المؤقت المحلي صراحةً** عند تهيئة الاتصال · تعطيل أزرار الحفظ عند الانقطاع مع شريط أحمر ثابت |
| **C-06** | **التوقيت من الخادم لا من الجهاز** | قواعد الحماية تفرض تساوي حقل الوقت مع وقت الطلب — **فلا يُزوَّر التاريخ بتغيير ساعة الجهاز** |
| **C-07** | **طبقة التفويض الوحيدة المعتمدة هي قواعد الحماية + العمليات السحابية** | **إخفاء الزر ليس حماية، والتحقق داخل كود التطبيق ليس حماية** |
| **C-08** | **الحذف مرفوض نهائياً** على كل الدفاتر والمستندات المعتمدة لكل المستخدمين **بمن فيهم المالك** | البديل الوحيد: الإلغاء بالوسم — ★★ **وسببُه اختياري** (`ADR-0020`) |
| **C-09** | **سجل التدقيق للإضافة فقط** — لا يُعدَّل ولا يُحذف من أحد | **الشرط الوحيد** الذي يجعل تعديل الدفاتر آمناً |
| **C-10** | **وحدة القياس جزء من هوية النوع** ولا تتغيّر بعد أول حركة | تغييرها يفسد كل الأرصدة التاريخية |
| **C-11** | **موقع Firestore الجغرافي لا يُغيَّر بعد الإنشاء** | قرار لا رجعة فيه — راجع `RD-001` |
| **C-12** | **تكلفة القراءات والكتابات هي المحرّك الأساسي للفاتورة** | إلزام بالملخصات الجاهزة · إعادة الاحتساب **بتجميع** · تجنّب المستمعين واسعي النطاق · **تنبيهات ميزانية من اليوم الأول** |

## 5. ما لا وجود له في النظام (نفي صريح — `GR-55`)

هذه محذوفة **بقرار المالك**، وذكرها هنا يمنع إعادة إدخالها سهواً:

| المحذوف | البديل المعتمد |
|---|---|
| **الحركات التصحيحية والعكسية** | التعديل المباشر + الوسم بالإلغاء + سجل التدقيق (`A-14`) |
| دمج نوعين | التعطيل وإعادة الإدخال الصحيح |
| تنبيه انحراف كمية التوريد | — |
| متصفّح الأيام السابقة للقراءة في شاشة المخزون | **شاشة «متبقي الأيام السابقة» للعمل** + تقارير `M19` |
| الحجز المؤقت للكميات | التحقق **لحظة الاعتماد فقط** داخل المعاملة الذرّية |
| تسجيل محاولات الإرسال ووقتها ونتيجتها | — (الصلاحية باقية كضابط لظهور الزرين) |
| معاينة «ماذا يرى هذا المستخدم» | مقارنة المستخدم بدوره |
| حقل معرّف الجهاز الأخير | تتبّع الأجهزة في سجل التدقيق |
| وحدة النسخ الاحتياطي داخل التطبيق | موثوقية المنصة السحابية المُدارة |
| **حقل كلمة المرور في سجل المستخدم** | تديره خدمة المصادقة بالكامل ولا يُخزَّن إطلاقاً |
| **اسم المشتري والخصم في البيع النقدي** | يُدخَل السعر النهائي مباشرةً بشرط ألا يقل عن الحد الأدنى (`ت-06`) |
| **المبلغ الفائض في الخصومات** | غير موجود إطلاقاً — وترفضه قاعدة الحماية لو أُرسل من خارج التطبيق |
