# المتطلبات غير الوظيفية (NFR) — QTMS

| البند | القيمة |
|---|---|
| **الإلزامية** | **M** |
| **الطبيعة** | **LIVING** — تُراجَع مع كل إصدار رئيسي |
| **المالك** | BA / ARCH |
| **المصدر** | القسم 13 من المستند الوظيفي + قيود مبثوثة في الأقسام 2 و9 و12 |

> أضفناه** ويكفي اعتراض واحد لتغييره · ⏳ = يحتاج خط أساس فعلي.

## NFR-SEC — الأمن

| # | المتطلب |
|---|---|

| `NFR-SEC-02` | 📄 **كلمات المرور مُدارة في خدمة المصادقة** ولا تُخزَّن في قاعدة البيانات إطلاقاً |
| `NFR-SEC-03` | 📄 **اتصال مشفَّر إلزامي** بين التطبيق والمنصة |
| `NFR-SEC-04` | 📄 **فحص العميل الرسمي** — رفض أي عميل غير التطبيق الرسمي |
| `NFR-SEC-05` | 📄 **جلسات محدودة المدة** + قفل الحساب بعد محاولات دخول فاشلة متتالية (`BR-M1-05`) |
| `NFR-SEC-06` | 📄 **نطاق المصادر مفروض أمنياً لا عرضياً** (`GR-23`) — ومن حاول قراءة أو كتابة مصدر خارج نطاقه من خارج التطبيق **يُرفض طلبه** |
| `NFR-SEC-07` | 📄 **سجل التدقيق غير قابل للتعديل ولا الحذف من أحد** بمن فيهم المالك (`GR-08`) |
| `NFR-SEC-08` | 📄 **الرفض هو الأصل والسماح استثناء صريح مكتوب** — أي مسار لم يُذكر صراحةً = ممنوع (`GR-10` · §6.5) |
| `NFR-SEC-09` | 📄 **لا ينجح أي تعديل بلا قيد مقابل في سجل التدقيق** — شرط بنيوي لا خيار (`BR-M18-03`) |
| `NFR-SEC-10` | 📄 **كل صلاحية لها مقابل مكتوب في قواعد الحماية** — وأي صلاحية بلا مقابل **تُعتبر غير مُنفَّذة أمنياً** (`BR-M1-07`) |
| `NFR-SEC-11` | 🔶 **لا ترويسة تكشف مكدّس النظام أو جهة التطوير** — إزالتها هي القاعدة الأمنية القياسية لا إضافتها |

## متطلبات غير وظيفية **لم يحددها المصدر ولم نخترع لها أرقاماً**

| البند | لماذا تُرك مفتوحاً |
|---|---|
| **هدف التوافر (Uptime/SLA)** | النظام يعتمد كلياً على توافر المنصة السحابية المُدارة، ولا يملك الفريق التحكم فيه. يُوثَّق كـ**التزام المزوّد** لا كهدف داخلي — راجع `docs/13-operations/sla-slo-sli.md`. |
| **هدف RPO/RTO للاسترجاع** | لم يذكره المصدر، وهو قرار تشغيلي يعتمد على خطة المزوّد المختارة — راجع `docs/06-database/backup-and-recovery-policy.md`. |
| **حد أقصى للمستخدمين المتزامنين** | لم يُذكر. النظام لمنشأة واحدة بفريق صغير؛ ووضع رقم مخترَع يُنتج تخطيط سعة وهمياً. يُقاس من خط أساس فعلي — `docs/10-performance/capacity-planning.md`. |
| **سقف تنبيه الميزانية الشهري** | **قيمة مالية يحددها المالك حصراً.** بند إلزامي في `release-checklist.md` والخطوة صفر. |
